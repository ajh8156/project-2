## 완료된 작업

### 데이터 소스
- `t_orders_summary` 커스텀 쿼리 연결 (WHERE order_status = 'delivered' 포함)
- `t_customer_summary` BigQuery 테이블 생성 후 Looker 연결 (맞춤 검색어 방식)

### 커스텀 쿼리 최종본 (핵심 추가 필드)
```sql
is_delayed_first    -- 첫 구매 기준 배송 지연 여부
is_low_rating_first -- 첫 구매 기준 저평점 여부
is_repeat_customer  -- 재구매 고객 여부
customer_order_seq  -- 고객별 구매 순번
WHERE order_status = 'delivered'
```

### KR 스코어카드 완료

| 카드 | 값 | 목표 | 배경색 |
|------|-----|------|--------|
| KR1 재구매율 | 3.0% | 4.5% | `#E6F4EA` (TF3) |
| KR2 주문수/인 | 1.033 | 1.06 | `#E6F4EA` (TF3) |
| KR3 재구매 비중 | 6.14% | 9.0% | `#E6F4EA` (TF3) |
| KR4 지연율 | 8.15% | 6.0%↓ | `#FCE8E6` (TF1) |
| KR5 저평점 | 12.74% | 10.5%↓ | `#FEF7E0` (TF2) |
| BF cohort | 0.56% | — | `#FCE8E6` |

**색상 기준**: 목표 달성 여부가 아닌 **TF 책임** 기준으로 구분  
(TF3=녹색, TF1=빨강, TF2=노랑)

### 트러블슈팅 기록

| 문제 | 원인 | 해결 |
|------|------|------|
| KR5 14.57% → 12.82% 불일치 | `order_status = 'delivered'` 필터 누락 | WHERE 조건 추가 |
| 차트 필터 비활성화 (strikethrough) | 스코어카드에 행 단위 필터 적용 불가 | SQL에 `_first` 필드 사전 계산으로 해결 |
| t_customer_summary 프로젝트 미표시 | 데이터셋 레벨 권한이라 브라우징 불가 | 맞춤 검색어(커스텀 쿼리)로 우회 |

## 발견 요약 (최종 확정)

```
· 첫구매 후 97%가 이탈 (재구매율 3.0%)
· BF 고객은 0.56%만 재구매 — 평시의 1/5
· 재구매율은 5점 고객에서 가장 높고 (3.09%), 1~4점은 2.5~2.9%로 낮음
· 정시 배송 3.13% vs 지연 배송 2.54% (-0.59%p)
· AARRR 병목: Retention → TF 3개로 해결
```

> ⚠️ "5점에서만 만들어진다"는 표현은 과장. 1~4점도 재구매 존재(2.5~2.9%).  
> 정확한 표현: "5점에서 유의미하게 높아진다"
