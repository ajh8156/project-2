# Looker Studio 발표용 대시보드 설계서

> 작성일: 2026-04-17
> 목적: 분석 결과를 청중(심사자·팀원·이해관계자)에게 스토리로 전달하는 발표용 대시보드
> 실무 추적용 대시보드(`dashboard_design.md`)와 **별개**로 제작

---

## 실무용 vs 발표용 비교

| 항목 | 실무 추적용 (기존) | 발표용 (이 문서) |
|------|------------------|----------------|
| 중심 질문 | "KR이 지금 어디까지 왔나?" | "우리가 무엇을 발견했고 무엇을 제안하는가?" |
| 페이지 역할 | 팀별 KR 모니터링 | 분석 챕터 1개 = 페이지 1개 |
| 필터 | 팀별 자유 탐색 | 최소화 (발표 중 혼선 방지) |
| 페이지 마무리 | 드릴다운 테이블 | 인사이트 + 액션 제안 박스 |
| 차트 수 | 페이지당 4~5개 | 페이지당 최대 3개 |
| 사용 시점 | 매주·매월 상시 운영 | 발표 당일 고정 스냅샷 |

---

## 전체 페이지 구조 (7페이지)

| 페이지 | 제목 | 핵심 메시지 | 사용 차트 |
|--------|------|------------|---------|
| P1 | 프로젝트 개요 & 데이터 소개 | 무엇을, 왜 분석했는가 | 텍스트 + 수치 카드 |
| P2 | 전사 KR 현황 요약 | 5개 KR 달성률 한눈에 | 게이지 + 진행률 바 |
| P3 | [발견 1] 재구매 패턴 | D+30이 최적 쿠폰 타이밍 | 코호트 히트맵 + 간격 히스토그램 |
| P4 | [발견 2] AOV & 번들 효과 | 다품목 구매 시 AOV +41~147% | 막대 비교 + 듀얼 축 추이 |
| P5 | [발견 3] 배송 지연 원인 | 셀러 귀책이 캐리어보다 크다 | 누적 막대 + 지역 랭킹 |
| P6 | [발견 4] 셀러·리뷰 상관 | 지연율↑ = 저평점↑ 인과관계 확인 | 산점도 + 비교 막대 |
| P7 | 팀별 액션 플랜 요약 | 6팀 × 즉시 실행 가능한 제안 | 테이블 카드 |

---

## 페이지별 설계 원칙

- **상단**: 이 페이지의 질문을 1~2문장으로 명시
- **중단**: 핵심 발견사항 차트 2~3개 (필터 최소, 강조색 사용)
- **하단 인사이트 박스**: `→ 발견:` + `→ 제안:` 고정 표시

### P1: 프로젝트 개요 & 데이터 소개

> **이 페이지의 질문**: 우리는 어떤 데이터로, 왜 이 분석을 했는가?

```
┌─────────────────────────────────────────────────────────────────┐
│  프로젝트명: Olist 이커머스 재구매율 개선 분석                   │
│  팀: [팀명]   분석 기간: 2016.09 ~ 2018.08   발표일: 2026-04-XX │
├──────────────────────┬──────────────────────┬───────────────────┤
│  데이터 규모          │  분석 프레임워크       │  핵심 목표 (OKR)  │
│  주문 99,441건        │  AARRR + KPI Tree     │  재구매율 3%→4.5% │
│  고객 96,096명        │  OKR (5개 KR)         │  (현재 달성 67%)  │
│  셀러 3,095명         │  6개 팀 분석          │                   │
├──────────────────────┴──────────────────────┴───────────────────┤
│  데이터 파이프라인                                               │
│  11개 CSV  →  Python JOIN  →  BigQuery  →  Looker Studio        │
└─────────────────────────────────────────────────────────────────┘
```

| # | 구성 요소 | 내용 |
|---|----------|------|
| 1-1 | 프로젝트 헤더 | 팀명, 분석 기간, 발표일 |
| 1-2 | 데이터 규모 카드 | 주문수·고객수·셀러수·카테고리수 수치 강조 |
| 1-3 | 분석 프레임워크 카드 | AARRR / KPI Tree / OKR |
| 1-4 | 핵심 목표 카드 | KR 5개와 목표값 한 줄 요약 |
| 1-5 | 데이터 파이프라인 | 텍스트 플로우 (CSV → Python → BigQuery → Looker) |

### P2: 전사 KR 현황 요약

> **이 페이지의 질문**: 5개 KR이 현재 얼마나 달성되었는가?

```
┌─────────────────────────────────────────────────────────────────┐
│  기준 기간: 2016.09 ~ 2018.08  (전체 분석 기간 고정)             │
├─────────────┬─────────────┬──────────────┬──────────┬──────────┤
│    KR1      │    KR2      │     KR3      │   KR4    │   KR5    │
│  재구매율   │  주문수/인   │  재구매비중  │ 배송지연율│저평점비중│
│ 3.00%→4.5% │ 1.03→1.06   │ 6.13%→9.0%  │8.16%→6.0%│12.82%→  │
│  달성 67%   │  달성 50%   │   달성 68%   │ 달성 진행│  10.5%   │
├─────────────┴─────────────┴──────────────┴──────────┴──────────┤
│  KR별 달성률 진행 바  (가로 5개 나란히)                          │
│  KR1 ████████░░  67%  │ KR2 █████░░░░░  50%  │ KR3 ███████░░  68% │
│  KR4 ████░░░░░░  진행  │ KR5 ████░░░░░░  진행                  │
└─────────────────────────────────────────────────────────────────┘
```

| # | 차트 | 유형 | 핵심 표시 내용 |
|---|------|------|--------------|
| 2-1 | KR1~5 스코어카드 | 수치 카드 5개 | 현재값 → 목표값 |
| 2-2 | KR 달성률 진행 바 | 가로 진행률 바 | 달성 % 색상 구분 (달성/미달) |

> **→ 발견**: KR1(재구매율)·KR3(재구매비중)은 67~68% 달성, KR2(주문수/인)는 50%로 가장 부진
>
> **→ 이후 페이지**: 각 KR 부진 원인을 P3~P6에서 분석별로 풀어냄

### P3: [발견 1] 재구매 패턴 분석

> **이 페이지의 질문**: 고객은 언제 다시 구매하는가? 쿠폰 타이밍이 맞는가?

```
┌─────────────────────────────────────────────────────────────────┐
│  "재구매 고객의 중앙 재구매 간격은 29일 — D+30 쿠폰이 최적"      │
├──────────────────────────────────┬──────────────────────────────┤
│  코호트 리텐션 히트맵              │  재구매 간격 분포 (히스토그램)│
│  첫구매월 × 경과 N월 = 재구매율   │  중앙값 29일 강조             │
│  색상 진할수록 리텐션 높음         │  D+7 · D+30 캠페인 라인 표시  │
│  → 어느 코호트가 잘 유지되나?     │  → D+30이 피크와 일치하는가? │
└──────────────────────────────────┴──────────────────────────────┘
```

| # | 차트 | 유형 | 계산 방법 |
|---|------|------|---------|
| 3-1 | 코호트 리텐션 | 피벗 히트맵 | 첫 구매월 × 경과 N월 후 재구매율 |
| 3-2 | 재구매 간격 분포 | 히스토그램 | 동일 고객 1차→2차 주문 날짜 차이 (일) |

> **→ 발견**: 재구매 고객의 중앙 간격은 29일. D+7 캠페인보다 D+30 타이밍이 실제 구매 패턴에 부합
>
> **→ 제안 (Marketing)**: 첫 구매 후 D+28~30 쿠폰 발송 자동화. D+7은 충동 구매 유도용으로 분리 운영

### P4: [발견 2] AOV & 번들 효과

> **이 페이지의 질문**: 다품목 구매가 실제로 AOV를 높이는가? 어떤 조합이 유효한가?

```
┌─────────────────────────────────────────────────────────────────┐
│  "2개 구매 시 AOV +41%, 3개+ 구매 시 +147% — 번들 전략 유효"    │
├──────────────────────────────────┬──────────────────────────────┤
│  구매 수량별 AOV 비교 (막대)       │  Co-purchase 매트릭스 (히트맵)│
│  1개: BRL 150                     │  카테고리 × 카테고리 조합 빈도│
│  2개: BRL 211  (+41%)             │  → 가장 자주 함께 사는 조합   │
│  3개+: BRL 371  (+147%)           │                              │
└──────────────────────────────────┴──────────────────────────────┘
```

| # | 차트 | 유형 | 계산 방법 |
|---|------|------|---------|
| 4-1 | 수량별 AOV 비교 | 그룹 막대 | item_count별 `price+freight` 평균 |
| 4-2 | Co-purchase 매트릭스 | 히트맵 | 동일 주문 내 카테고리 조합 빈도 |

> **→ 발견**: 다품목 구매 시 AOV 상승 효과가 통계적으로 유의미. 번들 전략은 KR2(주문수/인) 개선에도 기여 가능
>
> **→ 제안 (MD)**: Co-purchase 상위 조합 기반 번들 상품 기획. 무료배송 threshold를 BRL 200 이상으로 설정해 2개 구매 유도

### P5: [발견 3] 배송 지연 원인 분석

> **이 페이지의 질문**: 배송 지연은 셀러 탓인가, 캐리어 탓인가? 어디가 가장 심각한가?
> **기준 문서**: `logistics_v2.md` (2017 BF 실측 데이터 반영)

```
┌─────────────────────────────────────────────────────────────────┐
│  "지연의 주원인은 셀러 출고 지연 — 카테고리·지역별 집중 관리 필요" │
├──────────────────────────────────┬──────────────────────────────┤
│  출고 vs 배송 리드타임 (누적 막대) │  주(州)별 지연율 랭킹 (가로 막대)│
│  셀러 귀책: 출고까지 소요일       │  RJ 13.5% 최상위 강조         │
│  캐리어 귀책: 출고→도착 소요일    │  → 지역별 우선순위 확인        │
│  → 어느 쪽 비중이 더 큰가?        │                              │
├──────────────────────────────────┴──────────────────────────────┤
│  카테고리별 지연율 TOP10 (가로 막대)                              │
│  health_beauty 9.06% 등 / → 어떤 카테고리 셀러 교육 우선?        │
└─────────────────────────────────────────────────────────────────┘
```

| # | 차트 | 유형 | 계산 방법 |
|---|------|------|---------|
| 5-1 | 출고 vs 배송 리드타임 | 누적 막대 | `purchase→carrier` / `carrier→delivered` 평균 일수 |
| 5-2 | 주별 지연율 랭킹 | 가로 막대 (내림차순) | `customer_state`별 `delivered > estimated` 비율 |
| 5-3 | 카테고리별 지연율 | 가로 막대 TOP10 | 카테고리별 `delivered > estimated` 비율 |

> **→ 발견**: 전체 지연 중 셀러 출고 지연 비중이 캐리어보다 높음. 지역별(RJ 13.5%)뿐 아니라 카테고리별(health_beauty 9.06%)로도 집중 관리 대상 존재
>
> **→ 제안 (Logistics + Seller Ops)**: 지연 셀러 TOP20 출고 SLA 교육 우선 시행. RJ 지역 캐리어 계약 재검토. health_beauty 등 고지연 카테고리 셀러 별도 모니터링

### P6: [발견 4] 셀러 성과 & 리뷰 상관

> **이 페이지의 질문**: 배송 지연이 저평점으로 이어지는가? 어떤 셀러가 문제인가?

```
┌─────────────────────────────────────────────────────────────────┐
│  "지연 주문의 평균 리뷰 2.5점 vs 정시 주문 4.3점 — 1.8점 차이"  │
├──────────────────────────────────┬──────────────────────────────┤
│  리뷰 vs 지연율 산점도             │  정시 vs 지연 리뷰 비교 (막대)│
│  X: 셀러 지연율  Y: 평균 리뷰     │  정시: 4.3점 / 지연: 2.5점    │
│  색상: 셀러 등급 (S/A/B/C)        │  → 지연 영향 1.8점 정량화     │
│  → 지연↑ = 리뷰↓ 패턴 시각화     │                              │
└──────────────────────────────────┴──────────────────────────────┘
```

| # | 차트 | 유형 | 계산 방법 |
|---|------|------|---------|
| 6-1 | 리뷰 vs 지연율 산점도 | 산점도 | X: 셀러별 지연율, Y: 셀러별 평균 리뷰, 색상: 등급 |
| 6-2 | 정시 vs 지연 리뷰 비교 | 막대 비교 | 지연 Y/N별 평균 `review_score` |

> **→ 발견**: 지연 주문은 정시 주문 대비 평균 리뷰 1.8점 낮음. 배송 지연이 KR5(저평점비중) 악화의 직접 원인
>
> **→ 제안 (CX + Seller Ops)**: 지연 발생 즉시 고객 사전 알림 발송으로 리뷰 하락 완충. C등급 셀러 집중 관리

### P7: 팀별 액션 플랜 요약

> **이 페이지의 질문**: 각 팀이 지금 당장 실행할 수 있는 것은 무엇인가?

```
┌─────────────────────────────────────────────────────────────────┐
│  "분석 결과에서 도출된 6개 팀 즉시 실행 제안"                    │
├────────────┬────────────────────────────┬──────────────────────┤
│    팀      │         핵심 발견           │      즉시 제안        │
├────────────┼────────────────────────────┼──────────────────────┤
│ Marketing  │ 재구매 중앙 간격 29일       │ D+28~30 쿠폰 자동화 / BF cohort D+30·D+60 추적 │
│ MD         │ 다품목 AOV +41~147%        │ 번들 기획 + threshold BRL200 / BF 다품목 13~14% 목표 │
│ Logistics  │ 셀러 출고 지연 > 캐리어    │ 카테고리+지역별 지연 셀러 TOP20 출고 SLA 교육     │
│ CX         │ 지연→저평점 1.8점 차이     │ 지연 발생 즉시 사전 알림 / 저평점 48시간 내 대응   │
│ Seller Ops │ 온보딩 완주율 44.7% 부진   │ 온보딩 퍼널 이탈 단계 개선 / 첫판매 소요일 44→25일 │
│ Product/UX │ UX 귀책 저평점 18%         │ ETA 노출·리뷰 요약 등 PDP 신뢰 요소 강화          │
└────────────┴────────────────────────────┴──────────────────────┘
```

| # | 구성 요소 | 내용 |
|---|----------|------|
| 7-1 | 팀별 액션 테이블 | 팀 × 발견 × 제안 3열 구성 |
| 7-2 | KR 재확인 카드 | 각 제안이 어느 KR에 기여하는지 매핑 |

> **→ 발견 → 제안 흐름 완결**: P3~P6의 4가지 발견이 각 팀의 실행 항목으로 연결됨
>
> **→ 다음 단계**: 실무 대시보드(`dashboard_design.md`)로 지속 모니터링

---

## 발표 흐름 시뮬레이션

```
P1 (배경)  →  P2 (현황)  →  P3 (발견1)  →  P4 (발견2)
                                             ↓
P7 (제안)  ←  P6 (발견4)  ←  P5 (발견3)
```

**스토리 라인**: 데이터 소개 → KR 현황 확인 → 재구매 패턴 발견 → AOV 번들 효과 확인 → 배송 지연 원인 규명 → 셀러·리뷰 인과관계 → 6팀 제안으로 마무리

---

## 제작 시 유의사항

- **필터 제거**: 발표 중 청중이 필터를 건드리면 혼선 발생 → 기간 고정, 필터 숨기기
- **강조색 통일**: 문제/부정 지표 = 빨강(`#ea4335`), 인사이트/제안 = 파랑(`#1a73e8`)
