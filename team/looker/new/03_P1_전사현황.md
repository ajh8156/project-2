# 03. P1 전사 현황 — "재구매 구조가 없다"

> 백업 슬라이드: 슬2(결론) · 슬3(3축 신호등) · 슬4(RFM)
> 차트 수: 9개

## 이 페이지가 뜻하는 것

발표의 첫 결론 "Olist에는 재구매 구조가 없습니다"를 **데이터로 증명하는 페이지**입니다.

```
청중이 P1을 펼치면 — 발표 슬2~4를 다시 본 것과 같은 충격을 받아야 합니다.
"재구매율 3.0% / BF cohort 0.56% / 신호등 3축 빨강 / RFM 이탈재구매 다수"
```

각 차트는 발표 슬라이드의 어느 한 장을 뒷받침합니다.

| 차트 # | 이름 | 백업 슬라이드 |
|---|---|---|
| 1-1 | 헤더 + 데이터 규모 | (페이지 안내) |
| 1-2 | KR1~5 게이지 5개 | 슬1·슬25 |
| 1-3 | BF cohort 30일 재구매 카드 | 슬2 결론의 충격 수치 |
| 1-4 | 월별 KR 추이 (멀티라인) | 슬2 (트렌드 확인) |
| 1-5 | AARRR 3축 신호등 | 슬3 |
| 1-6 | RFM 세그먼트 분포 | 슬4 |
| 1-7 | G1 신규고객 추이 | 가드레일 |
| 1-8 | G2 AOV 추이 | 가드레일 |
| 1-9 | 인사이트 박스 (텍스트) | "→ 발견" 정리 |

## 차트별 상세

### 1-1. 헤더 + 데이터 규모 (텍스트)

**의미**: 청중이 어떤 데이터 위에서 그려진 결론인지를 한눈에 인지하도록.

**만드는 법**:
1. `삽입` → `텍스트` 박스를 캔버스 상단에 그리기
2. 다음 텍스트 입력:

```
Olist 재구매 구조 진단 · 2018년 컨설팅 보고서
분석 기간: 2016.09 ~ 2018.08  ·  주문 99,441건  ·  고객 96,096명  ·  셀러 3,095명
```

3. 폰트 크기: 제목 24pt · 본문 12pt
4. 정렬: 가운데

### 1-2. KR1~5 게이지 5개

**의미**: 발표 핵심 5개 KR의 현재값을 한눈에. "어디까지 왔는가"를 가장 압축적으로 보여주는 영역.

**차트 종류**: 스코어카드 (5개를 가로로 나란히)

**공통 설정**:
- 데이터 소스: KR1만 `t_customer_summary`, 나머지는 `t_orders_summary`
- 비교 기간: 사용 안 함 (목표값 비교는 텍스트로 표현)

**KR별 측정항목**:

| KR | 측정항목 (Metric) | 표시 형식 | 비교 텍스트 |
|----|------------------|---------|------------|
| KR1 재구매율 | `is_repeat` 평균 (`t_customer_summary`) | 백분율 1자리 | `현재 3.00% → 목표 4.5%` |
| KR2 주문수/인 | `order_count` 평균 (`t_customer_summary`) | 소수 4자리 | `현재 1.0334 → 목표 1.06` |
| KR3 재구매 비중 | `is_repeat_customer` 평균 (`t_orders_summary`) | 백분율 2자리 | `현재 6.13% → 목표 9.0%` |
| KR4 지연율 | `is_delayed` 평균 (`t_orders_summary`, 필터: `customer_order_seq=1`) | 백분율 2자리 | `현재 8.16% → 목표 6.0%` |
| KR5 저평점 비중 | `is_low_rating` 평균 (`t_orders_summary`, 필터: `customer_order_seq=1, review_score IS NOT NULL`) | 백분율 2자리 | `현재 12.82% → 목표 10.5%` |

**스타일**:
- 폰트 크기 36pt 이상 (뒷자리에서도 보이게)
- 색상: 모두 파랑(`#1A73E8`) — 단, KR4·KR5만 적색(`#EA4335`)으로 "문제" 신호 강조

**만드는 단계 (KR1 예시)**:
1. `차트 추가` → `스코어카드` 선택, 캔버스 좌상단에 배치
2. 우측 패널 `설정` → 데이터 소스 `t_customer_summary` 선택
3. `측정항목` 칸에 `is_repeat` 끌어 놓기 → 집계 `평균`
4. `지표 이름` 자리에 `KR1 재구매율` 입력
5. `스타일` 탭 → 숫자 형식 `백분율 (1자리)` → 폰트 36pt
6. 위 5번 KR 모두 같은 방식 반복

### 1-3. BF cohort 30일 재구매 카드

**의미**: 슬2의 결정타. "BF에서 만든 고객조차 0.56%만 돌아왔다" — 평시 3.0%의 1/5 수준이라는 충격을 시각화.

**차트 종류**: 스코어카드 (큼직하게)

**계산 로직**: 2017 BF(11/24~26) 첫 구매자 중, 첫 구매로부터 30일 이내 재구매한 비율.

**BigQuery 보조 SQL — 미리 한 번 계산해서 카드에 표시**:

```sql
WITH bf_buyers AS (
  SELECT customer_unique_id, MIN(DATE(purchase_timestamp)) AS first_bf_date
  FROM `olist-team-analysis.olist_analysis.t_orders_summary`
  WHERE DATE(purchase_timestamp) BETWEEN '2017-11-24' AND '2017-11-26'
    AND order_status = 'delivered'
  GROUP BY customer_unique_id
),
re_buyers AS (
  SELECT bf.customer_unique_id
  FROM bf_buyers bf
  JOIN `olist-team-analysis.olist_analysis.t_orders_summary` o
    ON bf.customer_unique_id = o.customer_unique_id
  WHERE DATE(o.purchase_timestamp) > bf.first_bf_date
    AND DATE(o.purchase_timestamp) <= DATE_ADD(bf.first_bf_date, INTERVAL 30 DAY)
  GROUP BY bf.customer_unique_id
)
SELECT
  COUNT(DISTINCT re_buyers.customer_unique_id) / COUNT(DISTINCT bf_buyers.customer_unique_id) * 100
    AS bf_cohort_30d_pct
FROM bf_buyers
LEFT JOIN re_buyers USING (customer_unique_id);
```

이 결과(예: 0.56)를 Looker 스코어카드에 직접 표시하기 어렵다면, **텍스트 박스로 대체**하는 것도 좋습니다 — 발표용이라 단순 표시가 우선.

**텍스트 박스 대체안 (가장 안정적)**:
```
BF cohort 30일 재구매율
0.56%
참고: 평시 3.00% (의 1/5)
```
폰트 크기 32pt, 배경색 적색 약함(`#FCE8E6`), 발표용으로 충분히 충격적.

### 1-4. 월별 KR 추이 (멀티라인)

**의미**: 5개 KR이 시간에 따라 어떻게 변해왔는가. 트렌드가 개선되고 있는지/정체인지 한눈에.

**차트 종류**: 시계열 차트

**설정**:
- 데이터 소스: `t_orders_summary`
- 기간 측정기준: `purchase_timestamp` (월 단위)
- 측정항목 4개 (KR1은 고객 단위라 별도 차트 권장 — 여기선 KR2~5만)
  - `is_repeat_customer` 평균 → KR3
  - `is_delayed` 평균 → KR4
  - `is_low_rating` 평균 → KR5
  - `order_id` COUNT_DISTINCT / `customer_unique_id` COUNT_DISTINCT → KR2 (Looker 계산식 활용)

**스타일**:
- 각 라인 색상 통일: KR3 녹색 / KR4 적색 / KR5 노란색 / KR2 회색
- 우측 Y축에 KR2(주문수/인) 별도 스케일 — `이중 축` 옵션 켜기
- 하단 범례 표시
- 목표선 (참조선): KR4 6.0%, KR5 10.5% 점선 추가

**만드는 단계**:
1. `차트 추가` → `시계열 차트` 선택
2. 데이터 소스 `t_orders_summary` 지정
3. 기간 측정기준에 `purchase_timestamp` 끌어 놓고 `MONTH` 선택
4. 측정항목에 위 4개 필드 차례로 추가
5. `스타일` → `참조선` → 목표값 추가 (KR4=0.06, KR5=0.105)

### 1-5. AARRR 3축 신호등

**의미**: 슬3 그대로. 청중이 "어느 단계가 무너져 있나"를 신호등 색깔로 즉시 인지.

**차트 종류**: 스코어카드 3개 가로 배치 + 조건부 색상

**3개 카드 구성**:

| 단계 | 측정항목 | 임계 색상 |
|------|---------|---------|
| Acquisition | 신규고객 수 (월 평균) | 🟢 녹색 (충분) |
| Activation | 첫 구매 저평점 비중 | 🟡 노랑 (12.82%) |
| Retention | 재구매율 | 🔴 적색 (3.0%) |

**만드는 법**:
- 스코어카드 3개를 한 줄로 배치
- 각 카드 배경색을 조건부로 (스타일 → 배경 → 단색)
  - Acquisition 카드: `#E6F4EA` (녹색 약함)
  - Activation 카드: `#FEF7E0` (노랑 약함)
  - Retention 카드: `#FCE8E6` (적색 약함)
- 카드 위에 텍스트 라벨: 🟢 / 🟡 / 🔴 이모지 또는 도형으로 표시

**대안**: 단순히 텍스트 박스 3개로 만들어도 됨 (발표용이라 데이터 직접 연결이 필수는 아님)

### 1-6. RFM 세그먼트 분포

**의미**: 슬4 백업. "이탈재구매 2,562명"이 어디 있는지 시각화.

**차트 종류**: 산점도 (R × F) 또는 가로 막대 (세그먼트별 인원)

**가장 쉬운 버전 — 가로 막대**:
- 데이터 소스: `t_customer_summary` (또는 별도 RFM 집계 테이블)
- 차원: `rfm_segment` (직접 만들어야 함)
- 측정항목: `customer_unique_id` COUNT_DISTINCT

**RFM 세그먼트 만드는 SQL** (BigQuery에서 미리):

```sql
CREATE OR REPLACE TABLE `olist-team-analysis.olist_analysis.t_rfm_segment` AS
WITH rfm AS (
  SELECT
    customer_unique_id,
    DATE_DIFF(DATE '2018-08-31', MAX(DATE(purchase_timestamp)), DAY) AS recency_days,
    COUNT(DISTINCT order_id) AS frequency,
    SUM(price + freight_value) AS monetary
  FROM `olist-team-analysis.olist_analysis.t_orders_summary` o
  JOIN `olist-team-analysis.olist_analysis.t_order_items` oi USING (order_id)
  WHERE o.order_status = 'delivered'
  GROUP BY customer_unique_id
)
SELECT
  customer_unique_id, recency_days, frequency, monetary,
  CASE
    WHEN recency_days <= 90 AND frequency >= 2 THEN '충성'
    WHEN recency_days <= 90 AND frequency = 1  THEN '신규활성'
    WHEN recency_days  > 90 AND frequency >= 2 THEN '이탈재구매 ★'
    WHEN recency_days  > 90 AND frequency = 1  THEN '일회성이탈'
    ELSE '기타'
  END AS rfm_segment
FROM rfm;
```

이 테이블을 Looker에 추가 → 가로 막대 차트로 세그먼트별 인원 표시. 핵심 막대(`이탈재구매 ★`)에 강조 색상.

### 1-8. G2 AOV 추이

**의미**: 가드레일. "할인·번들 때문에 객단가가 떨어지는가" 모니터링.

**차트 종류**: 시계열 차트 (단일 라인)

**설정**:
- 데이터 소스: `t_orders_summary` (또는 `t_order_items` 합산)
- 기간 측정기준: `purchase_timestamp` (월)
- 측정항목: `(price + freight_value)` SUM / `order_id` COUNT_DISTINCT

**Looker 계산된 필드 권장**:
```
필드 이름: aov
공식:      SUM(price + freight_value) / COUNT_DISTINCT(order_id)
주의:      t_order_items에서 만들면 정확. t_orders_summary에 order_total 컬럼이 이미 있으면 그걸 평균.
```

### 1-9. 인사이트 박스 (텍스트)

**의미**: 페이지 결론을 발표자 없이도 읽을 수 있게 정리.

**만드는 법**:
1. 페이지 하단에 텍스트 박스 그리기
2. 배경색 회색 약함(`#F1F3F4`)
3. 다음 텍스트 입력:

```
→ 발견
  · 첫 구매 후 97%가 이탈 (재구매율 3.0%)
  · BF에서 유입된 고객은 0.56%만 재구매 — 평시의 1/5
  · AARRR 신호등: Acquisition 🟢 / Activation ⚠️ / Retention 🚨
  · RFM에서 "이탈재구매" 세그먼트 2,562명 = 우선 회복 타겟

→ 슬라이드 백업: 슬2(결론) · 슬3(3축 신호등) · 슬4(RFM)
```

폰트: 제목 16pt 굵게 / 본문 12pt
