## 차트별 상세

### 2-1. 평점별 재구매율 (세로 막대) ★ 발표 피크

**의미**: 슬7의 좌측 차트. **재구매가 5점에서만 만들어진다**는 발견을 시각으로 보여줌.

**차트 종류**: 세로 막대 (열)

**설정**:
- 데이터 소스: `t_orders_summary`
- 차원: `review_score` (1~5점)
- 측정항목: `is_repeat_customer` 평균 (= 다음 주문이 있었던 비율)

**필터**:
- `customer_order_seq = 1` (첫 구매에만 한정 — 그 후 재구매했는가가 핵심)
- `review_score IS NOT NULL`

**예상 결과 (슬7 기준)**:
| review_score | is_repeat 평균 |
|---|---|
| 1점 | 약 2.4% |
| 2점 | 약 2.5% |
| 3점 | 약 2.5% |
| 4점 | 약 2.5% |
| 5점 | **3.12%** ★ |

**스타일**:
- 5점 막대만 녹색(`#34A853`)으로 강조, 나머지는 회색(`#5F6368`)
- 데이터 라벨 표시 (각 막대 위에 % 숫자)
- Y축 0~4% 범위 고정 (변화량을 강조하기 위해)

**만드는 단계**:
1. `차트 추가` → `세로 막대 차트` 선택
2. 데이터 소스: `t_orders_summary`
3. 차원: `review_score` 끌어 놓기
4. 측정항목: `is_repeat_customer` → 평균
5. 필터 추가: `customer_order_seq` Equals `1`
6. 스타일 → 막대별 색상 → 5점만 녹색으로 변경
7. Y축 → 사용자 지정 범위 0~0.04

> **검증**: 슬7 본문에 적힌 5점=3.12% 와 결과가 비슷하게 나오는지 꼭 확인.

### 2-2. 정시 vs 지연 재구매율 (세로 막대) ★ 발표 피크

**의미**: 슬7의 우측 차트. **5점을 결정하는 것은 배송**이라는 발견을 한 번 더.

**차트 종류**: 세로 막대 (2개)

**설정**:
- 데이터 소스: `t_orders_summary`
- 차원: `is_delayed` (0=정시, 1=지연)
- 측정항목: `is_repeat_customer` 평균

**필터**: `customer_order_seq = 1`

**예상 결과**:
| is_delayed | is_repeat 평균 |
|---|---|
| 0 (정시) | 3.04% |
| 1 (지연) | 2.51% |

차이 -0.53%p가 핵심 메시지.

**스타일**:
- 정시 막대: 녹색 / 지연 막대: 적색
- 데이터 라벨: 백분율 2자리
- 차원 라벨을 `정시 배송` / `지연 배송`으로 바꾸려면 `차원 이름 변경`

**계산된 필드 권장 (라벨 보기 좋게)**:
```
필드 이름: delivery_status_label
공식:      CASE WHEN is_delayed = 1 THEN '지연 배송' ELSE '정시 배송' END
```

이 필드를 차원으로 사용하면 X축 라벨이 깔끔.

### 2-3. 저평점 원인 분해 (도넛)

**의미**: 슬6 그대로. 저평점이 4개 팀에 분산되어 있어서 **한 팀이 단독 해결 불가** → TF 정당성의 핵심 근거.

**차트 종류**: 원형/도넛 차트

**주의**: 슬6 본문(배송 42% / CS 20% / 상품 20% / UX 18%)은 **CX 리뷰 텍스트 분류 결과**입니다. 이는 자동 집계가 아니라 사람이 분류한 결과라, BigQuery에 직접 컬럼이 있을 가능성이 낮습니다.

**두 가지 방법**:

**방법 A. 이미 분류 완료된 데이터가 있는 경우**
- 데이터 소스: 분류 결과가 담긴 별도 테이블 (예: `t_review_cause`)
- 차원: `cause_category` (배송/CS/상품/UX)
- 측정항목: `review_count` SUM

**방법 B. 분류 데이터가 없는 경우 (가장 현실적)**
- 도넛 차트 대신 **이미지 또는 정적 도넛**으로 표현
- Looker `삽입` → `이미지` 메뉴로 슬6에 사용한 도넛 그래픽을 그대로 삽입
- 또는 텍스트 + 색깔 막대로 시각화:

```
저평점 원인 분포 (CX 리뷰 텍스트 분류 기준)
████████████████████████████████████████  배송   42% (Logistics)
████████████████████                       CS     20% (CX)
████████████████████                       상품    20% (Seller Ops)
██████████████████                         UX     18% (Product)
```

> 발표용 1회성 시각이라 방법 B(이미지/정적)도 충분합니다. 정확도가 핵심이 아니라 "4팀 분산" 메시지가 핵심.

### 2-4. KPI Tree × AARRR 다이어그램 (이미지)

**의미**: 슬5 그대로. 수식 병목 = 여정 병목 = Retention 이라는 일치 구조를 시각화.

**Looker Studio에서 직접 그리기 어려움**: 화살표·트리 다이어그램은 Looker 기본 차트에 없습니다.

**권장**: 슬5에 사용한 다이어그램을 PNG/JPG로 저장한 후, Looker `삽입` → `이미지`로 끌어다 놓기.

**대체안 (텍스트로만)**:
```
GMV = Orders × AOV
Orders = Customers × Frequency
                   93,104     1.0334  ← 수식 병목 (빨강)

AARRR 퍼널:
  Acquisition ✅ → Activation ⚠️ → Retention 🚨 → Revenue ⚠️ → Referral ⚪
                                    └ 수식 병목과 일치 ┘
```

이 텍스트를 박스에 넣고 Frequency 1.0334와 Retention을 적색으로 강조.

### 2-5. Finding 3개 + 가설 검증 표

**의미**: 슬8 백업. 통찰을 가설 검증으로 마무리하고 각 Finding을 책임 TF에 매핑.

**차트 종류**: 표 (Looker 표 차트 또는 텍스트 표)

**가장 쉬운 버전 — 텍스트 박스로 표 그리기**:

```
| Finding         | 한 줄                              | 가설   | 책임 TF       |
|-----------------|-----------------------------------|--------|--------------|
| ① 배송 지연      | 정시 3.04% vs 지연 2.51% (-0.53%p) | H1 ✅ | 🔴 TF1 배송   |
| ② 5점 편향      | 1~4점 동일 / 5점만 3.12%           | H2 ✅ | 🟡 TF2 평점   |
| ③ 재구매 유도 부재| CRM·추천·쿠폰 인프라 전무          | H3 ✅ | 🟢 TF3 재구매 |
```

이 표를 텍스트 박스로 만들거나, 구글 시트에 입력 후 Looker 표 차트로 끌어와도 됩니다.

**Looker 표 차트로 만드는 경우**:
1. 구글 시트 새 파일에 위 표를 입력
2. Looker `리소스` → `데이터 추가` → 구글 시트 연결
3. `차트 추가` → `표` 선택, 시트 데이터 연결
4. 스타일 → 행 배경색 교차 적용

### 2-6. 인사이트 박스 (텍스트)

**의미**: 페이지 결론.

**텍스트**:
```
→ 발견
  · 평점 1~4점은 재구매율 동일 (~2.5%) — 5점에서만 3.12%
  · 5점을 만드는 것은 정시 배송 (정시 3.04% vs 지연 2.51%)
```

## 검증 SQL (발표 전 한 번)

차트 2-1·2-2 결과가 슬7 본문 수치와 일치하는지 BigQuery에서 직접 확인.

```sql
-- 평점별 재구매율 (차트 2-1 검증)
SELECT
  review_score,
  AVG(is_repeat_customer) * 100 AS repeat_pct
FROM `olist-team-analysis.olist_analysis.t_orders_summary`
WHERE customer_order_seq = 1
  AND review_score IS NOT NULL
  AND order_status = 'delivered'
GROUP BY review_score
ORDER BY review_score;

-- 정시 vs 지연 재구매율 (차트 2-2 검증)
SELECT
  CASE WHEN delivered_customer_date > estimated_delivery_date THEN '지연' ELSE '정시' END AS delivery_status,
  AVG(is_repeat_customer) * 100 AS repeat_pct
FROM `olist-team-analysis.olist_analysis.t_orders_summary`
WHERE customer_order_seq = 1
  AND order_status = 'delivered'
GROUP BY delivery_status;
```
