### 3-4. 출고 vs 배송 리드타임 분리

**의미**: 지연이 셀러 탓(출고 지연)인가 캐리어 탓(배송 지연)인가 분리.

**차트 종류**: 누적 가로 막대 (월별)

**설정**:
- 데이터 소스: `t_orders_summary`
- 차원: `purchase_year_month` (또는 기간 측정기준 월)
- 측정항목 2개:
  - `delivery_outbound_days` 평균 (= `purchase` → `carrier`까지 = 셀러 출고 시간)
  - `delivery_carrier_days` 평균 (= `carrier` → `delivered`까지 = 캐리어 배송 시간)
- 누적 모드: 켜기

**컬럼이 없다면 계산된 필드로**:
```
필드 이름: outbound_days
공식:      DATE_DIFF(delivered_carrier_date, DATE(purchase_timestamp), DAY)

필드 이름: carrier_days
공식:      DATE_DIFF(delivered_customer_date, delivered_carrier_date, DAY)
```

**스타일**:
- 출고: 진한 적색 (셀러 귀책)
- 배송: 연한 회색 (캐리어 귀책)

## TF3 ★ (재구매 유도) 차트 5개 — 페이지 절반 차지

### 3-9. 월별 재구매율 추이 — 발표 핵심 KR

**의미**: KR1(3.0% → 4.5%)이 시간에 따라 어떻게 변해왔고 어디로 가야 하는가.

**차트 종류**: 시계열 차트 (단일 라인)

**설정**:
- 데이터 소스: `t_customer_summary` (월별 집계 필요시 BigQuery 보조 SQL)
- 기간 측정기준: 첫 구매 월 기준 (코호트 방식)

**대안 — 단순 월별**: 매월의 "그 달까지 누적된 재구매율"을 표시.

**BigQuery 보조 SQL — 월별 누적 재구매율**:

```sql
CREATE OR REPLACE TABLE `olist-team-analysis.olist_analysis.t_monthly_repeat` AS
WITH monthly AS (
  SELECT
    DATE_TRUNC(DATE(purchase_timestamp), MONTH) AS month,
    customer_unique_id
  FROM `olist-team-analysis.olist_analysis.t_orders_summary`
  WHERE order_status = 'delivered'
)
SELECT
  m.month,
  COUNT(DISTINCT CASE WHEN cs.order_count >= 2 THEN cs.customer_unique_id END)
  / COUNT(DISTINCT cs.customer_unique_id) AS repeat_rate
FROM monthly m
JOIN `olist-team-analysis.olist_analysis.t_customer_summary` cs USING (customer_unique_id)
WHERE cs.first_purchase_date <= LAST_DAY(m.month)
GROUP BY m.month
ORDER BY m.month;
```

이 테이블을 Looker에 추가 → 시계열 라인 차트.

**스타일**:
- 라인 색상: 녹색(`#34A853`)
- 굵기: 4px (가장 굵게 — 핵심 KR 강조)
- 참조선 2개:
  - 현재값 3.0% (회색 점선)
  - 목표값 4.5% (파랑 점선)
- 차트 크기: TF3 영역에서 가장 크게 (페이지 폭의 절반)

### 3-10. 코호트 리텐션 히트맵

**의미**: 어느 달에 유입된 고객이 가장 잘 돌아오는가. 캠페인 효과 측정의 기초.

**차트 종류**: 피벗 테이블 + 조건부 색상 (히트맵)

**설정**:
- 데이터 소스: `t_cohort_retention` (02 §5에서 만든 테이블)
- 행 차원: `cohort_month`
- 열 차원: `month_number`
- 측정항목: 리텐션율 = `active_customers / 첫달_active_customers`

**Looker에서 리텐션율 계산**:
첫 달 active_customers를 별도로 끌어 나누는 것이 까다로울 수 있어, BigQuery에서 미리 리텐션율까지 계산해서 가져오는 게 편함.

```sql
-- t_cohort_retention 업데이트 — 리텐션율 컬럼 추가
CREATE OR REPLACE TABLE `olist-team-analysis.olist_analysis.t_cohort_retention_pct` AS
WITH base AS (
  SELECT cohort_month, month_number, active_customers
  FROM `olist-team-analysis.olist_analysis.t_cohort_retention`
),
first_month AS (
  SELECT cohort_month, active_customers AS cohort_size
  FROM base WHERE month_number = 0
)
SELECT
  b.cohort_month,
  b.month_number,
  b.active_customers,
  b.active_customers / fm.cohort_size AS retention_rate
FROM base b
JOIN first_month fm USING (cohort_month);
```

**스타일**:
- 표 → 조건부 서식 → 색상 그라데이션 (낮을수록 흰색, 높을수록 진한 녹색)
- 백분율 1자리

### 3-11. 재구매 간격 분포

**의미**: 첫 구매 후 며칠 만에 재구매하는가. **D+30 캠페인이 맞는 타이밍**이라는 슬26 CTA의 근거.

**차트 종류**: 막대 차트 (히스토그램)

**설정**:
- 데이터 소스: `t_orders_summary` (재구매 고객만)
- 차원: `days_to_repurchase` (이미 컬럼이 있다면 사용)
- 측정항목: `customer_unique_id` COUNT_DISTINCT

**없다면 BigQuery 보조 SQL**:

```sql
CREATE OR REPLACE TABLE `olist-team-analysis.olist_analysis.t_repurchase_interval` AS
WITH ordered AS (
  SELECT
    customer_unique_id,
    DATE(purchase_timestamp) AS purchase_date,
    LAG(DATE(purchase_timestamp)) OVER (
      PARTITION BY customer_unique_id ORDER BY purchase_timestamp
    ) AS prev_purchase_date
  FROM `olist-team-analysis.olist_analysis.t_orders_summary`
  WHERE order_status = 'delivered'
)
SELECT
  customer_unique_id,
  DATE_DIFF(purchase_date, prev_purchase_date, DAY) AS days_to_repurchase
FROM ordered
WHERE prev_purchase_date IS NOT NULL;
```

**스타일**:
- 히스토그램 X축: 0~180일
- 참조선: D+7 / D+30 / D+60 (수직선)
- 중앙값(약 29일) 위치 강조

### 3-12. BF cohort 추적 ★ (TF3에서 가장 중요)

**의미**: 슬25 핵심. **"BF에서 만든 고객이 정말 돌아오는가"** 직접 확인.

**차트 종류**: 시계열 차트 + 큰 카드 조합 (또는 단일 라인 + 참조선)

**설정 (단순 버전)**:
- 데이터 소스: BigQuery 보조 SQL로 미리 만든 BF cohort 추적 테이블
- 기간: 2017-11-27 ~ 2018-08
- 측정항목: BF 코호트의 누적 재구매율 (D+30, D+60, D+90)

**BigQuery 보조 SQL**:

```sql
CREATE OR REPLACE TABLE `olist-team-analysis.olist_analysis.t_bf_cohort_tracking` AS
WITH bf_buyers AS (
  SELECT customer_unique_id, MIN(DATE(purchase_timestamp)) AS bf_date
  FROM `olist-team-analysis.olist_analysis.t_orders_summary`
  WHERE DATE(purchase_timestamp) BETWEEN '2017-11-24' AND '2017-11-26'
    AND order_status = 'delivered'
  GROUP BY customer_unique_id
),
re_purchases AS (
  SELECT
    bf.customer_unique_id,
    bf.bf_date,
    DATE(o.purchase_timestamp) AS repurchase_date,
    DATE_DIFF(DATE(o.purchase_timestamp), bf.bf_date, DAY) AS days_after_bf
  FROM bf_buyers bf
  JOIN `olist-team-analysis.olist_analysis.t_orders_summary` o
    USING (customer_unique_id)
  WHERE DATE(o.purchase_timestamp) > bf.bf_date
)
SELECT
  days_after_bf,
  COUNT(DISTINCT customer_unique_id) AS cumulative_repurchasers,
  COUNT(DISTINCT customer_unique_id) / (SELECT COUNT(*) FROM bf_buyers) AS cumulative_rate
FROM re_purchases
WHERE days_after_bf <= 180
GROUP BY days_after_bf
ORDER BY days_after_bf;
```

**Looker 차트**:
- 시계열 차트 (X: `days_after_bf`, Y: `cumulative_rate`)
- 참조선:
  - D+30 위치에 수직선 + 라벨 "현재 0.56%"
  - D+30 수평선 1.5% / 2.0% (목표 범위)
- 라인 색상: 녹색 굵게

**스타일**: TF3 영역에서 두 번째로 크게 (3-9 다음)

→ 슬라이드 백업: 슬11(이중 트랙) · 슬25(기대효과 3열 시계열)
