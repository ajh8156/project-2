# 01. 시작하기 — Looker Studio 처음 켜는 법

> 대상: Looker Studio를 거의 안 써본 초보자
> 목표: 빈 보고서를 만들고, BigQuery에 연결하고, 첫 차트를 넣는 곳까지

---

## 1단계 — Looker Studio 접속

1. 크롬 브라우저에서 https://lookerstudio.google.com 접속
2. 구글 계정으로 로그인 (팀 BigQuery 권한이 있는 계정 — 보통 본인의 학원 구글 계정)
3. 화면 좌측 상단 `+ 만들기` → `보고서` 클릭

---

## 2단계 — BigQuery 데이터 소스 연결

처음 보고서를 열면 "데이터 소스에 연결" 화면이 뜹니다.

1. **커넥터 선택**: 구글 커넥터 중 `BigQuery` 클릭
2. **권한 승인**: "승인" 버튼 누름 (처음 한 번만)
3. **프로젝트 선택**: `olist-team-analysis`
4. **데이터 세트 선택**: `olist_analysis`
5. **테이블 선택**: `t_orders_summary` 먼저 추가
6. 우측 하단 `추가` → `보고서에 추가` 클릭

이렇게 하면 첫 데이터 소스가 연결됩니다. 화면 빈 캔버스(흰색 영역)가 나타납니다.

### 나머지 두 테이블도 같은 방식으로 추가

상단 메뉴에서 `리소스` → `추가된 데이터 소스 관리` → `+ 데이터 추가`

- `t_order_items` 추가
- `t_marketing_funnel` 추가 (이번 v3에선 안 쓰지만 미리 연결해두면 편함)

> **3개 테이블이 보고서에 모두 연결되어 있어야 차트마다 원하는 테이블을 골라 쓸 수 있습니다.**

---

## 3단계 — 페이지 만들기 (3개)

상단 메뉴 `페이지` → `새 페이지` 클릭. 3번 반복해서 페이지 3개를 만듭니다.

| 페이지 번호 | 이름 (좌측 페이지 패널에서 더블클릭해서 변경) |
|---|---|
| 1 | `P1. 전사 현황 — 재구매 구조가 없다` |
| 2 | `P2. 핵심 통찰 — 5점=배송` |
| 3 | `P3. TF별 책임 KR 추적` |

---

## 4단계 — 차트 추가하는 기본 방법

화면 상단 `차트 추가` 메뉴에서 차트 유형을 고르고, 캔버스에 드래그합니다.

차트가 캔버스에 생기면 우측 패널에 두 가지가 보입니다:

| 패널 탭 | 의미 |
|--------|------|
| **설정** | 어떤 데이터를 어떻게 보여줄지 (차원·측정항목·필터) |
| **스타일** | 색상·폰트·정렬·테두리 등 시각 디자인 |

### 핵심 용어 (꼭 기억)

| 용어 | 한 줄 설명 | 예시 |
|------|----------|------|
| **데이터 소스** | 어느 테이블에서 데이터를 가져올지 | `t_orders_summary` |
| **차원 (Dimension)** | 그룹핑 기준 = "어떻게 쪼갤지" | `customer_state` (지역별로 쪼갬) |
| **측정항목 (Metric)** | 숫자 값 = "무엇을 셀지" | `COUNT(order_id)` (주문 수) |
| **필터** | 조건으로 데이터 일부만 사용 | `order_status = 'delivered'` 만 보기 |
| **계산된 필드** | 새 지표를 만드는 공식 | `is_delayed` = 지연 여부 (1 or 0) |
| **기간 측정기준** | 시간 차원 (월/주/일) | `purchase_timestamp` |

---

## 5단계 — 계산된 필드(Calculated Field) 만들기

대시보드의 핵심 지표(재구매율·지연율·저평점 비중)는 모두 **계산된 필드**로 만듭니다. 한 번 만들어두면 모든 차트에서 재사용 가능합니다.

### 만드는 방법

1. 좌측 메뉴 `리소스` → `추가된 데이터 소스 관리`
2. 사용할 테이블(예: `t_orders_summary`) 옆 `수정` 클릭
3. 우측 상단 `+ 필드 추가` 클릭
4. 이름·계산식 입력 → `저장`

### 필드 입력 예시 (재구매 여부)

```
필드 이름: is_repeat
공식:      CASE WHEN customer_order_seq >= 2 THEN 1 ELSE 0 END
유형:      숫자
```

> 02_지표_사전.md에 v3에서 사용할 모든 계산된 필드 공식이 정리되어 있습니다.

## 6단계 — 자주 쓰는 차트 유형 (5가지만 기억)

| 차트 유형 | 어떤 때 쓰나 | 이번 v3 사용 예 |
|---------|------------|---------------|
| **스코어카드** | 숫자 1개를 크게 보여줄 때 | KR1 재구매율 게이지, BF cohort 카드 |
| **시계열 차트** | 월별 추이 (날짜 X축) | 월별 KR 추이, 월별 재구매율 |
| **막대 차트 (가로)** | 항목별 순위·비교 | 주별 지연율 TOP10, 카테고리별 저평점 |
| **막대 차트 (세로)** | 카테고리 5개 이내 비교 | 평점별 재구매율, 정시 vs 지연 비교 |
| **피벗 테이블** | 두 차원 교차 (X × Y = 값) | 코호트 리텐션 히트맵 |

> 도넛·산점도는 1~2개만 쓰니 그때그때 차트 추가 메뉴에서 찾으면 됩니다.

## 7단계 — 색상 일괄 적용 (테마)

상단 `테마 및 레이아웃` → `테마` 탭 → `사용자 설정`

| 색상 슬롯 | 입력값 | 용도 |
|----------|-------|------|
| 색상 1 | `#1A73E8` (파랑) | 결론·기본 |
| 색상 2 | `#34A853` (녹색) | TF3 강조 |
| 색상 3 | `#EA4335` (적색) | TF1·문제 신호 |
| 색상 4 | `#FBBC04` (노란색) | TF2 강조 |

이렇게 한 번 설정하면 모든 차트가 같은 컬러 팔레트를 씁니다.

---

## 8단계 — 텍스트 박스 (인사이트 설명용)

각 페이지 하단에 "→ 발견:" "→ 제안:" 텍스트 박스를 넣습니다. 발표자가 없어도 청중이 혼자 읽고 이해할 수 있도록.

1. 상단 `삽입` → `텍스트` 선택
2. 캔버스에 박스 그리기
3. 텍스트 입력 → 폰트 크기 14pt, 굵게 권장
4. 배경색 연한 회색(`#F1F3F4`) 추천

---

## 9단계 — 보고서 공유 (제출 전 마지막)

우측 상단 `공유` 버튼:

1. **공유 가능한 링크 가져오기** → 권한: `링크가 있는 모든 사용자` · `보기` 선택
2. URL 복사 → 슬27 참고 슬라이드에 붙여넣기 + QR 코드 생성

> ⚠️ 권한을 `편집`으로 두면 청중이 차트를 망가뜨릴 수 있습니다. 반드시 `보기`로.

## 자주 막히는 지점 (FAQ)

**Q. 차트에 "데이터가 없습니다"가 뜬다**
A. 차원·측정항목 칸에 필드를 끌어다 놓아야 합니다. 빈 칸이면 그래프가 안 그려져요.

**Q. 계산된 필드가 "잘못된 공식"이라고 나온다**
A. 큰따옴표("") 대신 작은따옴표('')를 사용해야 합니다. `WHEN order_status = 'delivered'` ✅

**Q. BigQuery 비용이 걱정된다**
A. Looker Studio가 매번 BigQuery 쿼리를 날립니다. 절약하려면 데이터 소스 옆 `데이터 자격 증명` → `데이터 추출`로 스냅샷을 떠두면 됩니다. (발표용이라 추천)

**Q. 두 테이블을 합쳐 쓰고 싶다**
A. `리소스` → `데이터 결합` 으로 JOIN을 만들 수 있지만, 우리는 BigQuery에서 이미 통합 테이블을 만들어뒀으니 거의 쓸 일이 없습니다.
