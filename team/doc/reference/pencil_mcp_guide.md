# Pencil MCP 팀원 공유 가이드

**대상**: 데2터로말해조 팀원 전체  
**목적**: Claude Code + Pencil MCP로 발표 슬라이드 및 카드뉴스 제작  
**작성일**: 2026-04-18

---

## 사전 준비 (팀원 각자 설치 필요)

> 설치 방식은 **CLI** 또는 **VS Code 익스텐션** 중 편한 걸 선택하세요.  
> CLI가 어렵다면 VS Code 익스텐션 방식을 권장합니다.

---

### 방법 A — CLI 방식 (터미널 친숙한 분)

#### A-1. Claude Code CLI 설치

1. 브라우저에서 https://claude.ai/code 접속
2. 본인 OS에 맞는 설치 파일 다운로드 (Windows / Mac)
3. 설치 완료 후 터미널(또는 PowerShell) 실행
4. 아래 명령어로 설치 확인:

```bash
claude --version
```

정상 출력 예시: `claude 1.x.x`

#### A-2. Pencil MCP 서버 등록 (최초 1회)

```bash
claude mcp add pencil npx pencil-mcp
```

등록 확인:

```bash
claude mcp list
```

출력 목록에 `pencil` 항목이 보이면 완료입니다.

#### A-3. 실행

터미널에서 `claude` 입력 → 채팅창 열림 → 작업 시작

---

### 방법 B — VS Code 익스텐션 방식 (터미널 불편한 분)

#### B-1. VS Code 설치 확인

VS Code가 없다면 https://code.visualstudio.com 에서 설치

#### B-2. Claude Code 익스텐션 설치

1. VS Code 실행
2. 왼쪽 사이드바 **Extensions** 아이콘 클릭 (또는 `Ctrl+Shift+X`)
3. 검색창에 `Claude Code` 입력
4. **Claude Code (Anthropic)** 익스텐션 → **Install** 클릭
5. 설치 후 VS Code 재시작

#### B-3. Anthropic 계정 로그인

1. VS Code 재시작 후 왼쪽 사이드바에 Claude 아이콘 클릭
2. **Sign in** 버튼 클릭 → 브라우저에서 Anthropic 계정으로 로그인
3. 로그인 완료 후 VS Code로 돌아오면 채팅창 활성화

#### B-4. Pencil MCP 서버 등록 (최초 1회)

VS Code 내 터미널에서 실행 (`Ctrl+`` ` `` `로 터미널 열기):

```bash
claude mcp add pencil npx pencil-mcp
```

또는 VS Code 설정에서 직접 추가:
1. `Ctrl+Shift+P` → `Open User Settings (JSON)` 검색
2. 아래 내용 추가:

```json
{
  "claude.mcpServers": {
    "pencil": {
      "command": "npx",
      "args": ["pencil-mcp"]
    }
  }
}
```

3. 저장 후 VS Code 재시작

#### B-5. 연동 확인

1. Claude Code 채팅창 하단 또는 설정에서 **MCP 서버 목록** 확인
2. `pencil` 항목이 **연결됨(Connected)** 상태인지 확인

---

### 공통 — 연결 안 될 때

```bash
claude mcp remove pencil
claude mcp add pencil npx pencil-mcp
```

위 명령어 실행 후 Claude Code(또는 VS Code) 재시작

## 기본 사용법

### Step 1 — 새 디자인 파일 열기

Claude Code 채팅창에 아래처럼 입력:

```
Pencil MCP로 새 디자인 파일 열어줘
```

또는 기존 파일을 이어서 작업할 때:

```
team/seller_ops/pencil-new.pen 파일 열어줘
```

---

### Step 2 — 슬라이드 생성 요청

자연어로 요청하면 Pencil이 디자인을 생성합니다.

**표지 슬라이드 예시:**
```
발표 슬라이드 표지 만들어줘.
- 팀명: 데2터로말해조
- 주제: Olist 데이터 기반 재구매 구조 전환 전략
- 스타일: 깔끔한 비즈니스 톤, 네이비 계열 컬러
- 하단에 날짜(2026-05-09)와 팀원 이름 칸 추가
```

**내용 슬라이드 예시:**
```
두 번째 슬라이드: 문제 정의 섹션 만들어줘.
- 제목: "왜 재구매율이 낮은가?"
- 핵심 지표 3개를 카드 형태로 배치:
  1. 재구매율 3% (업계 평균 대비 낮음)
  2. 평균 주문 1.03회
  3. 저평점(1-2점) 비중 15%
- 색상: 문제를 강조하는 레드 포인트 컬러
```

**차트/분석 슬라이드 예시:**
```
세 번째 슬라이드: RFM 세그먼트 결과 슬라이드 만들어줘.
- 제목: "고객 세그먼트 분석 결과"
- 4개 그룹(Champions / Loyal / At Risk / Lost)을 2x2 그리드로 배치
- 각 그룹에 고객 수와 특징 텍스트 포함
```

---

### Step 3 — 수정 요청

```
첫 번째 슬라이드 배경색을 #1B2A4A(진한 네이비)로 바꿔줘
```

```
표지 폰트 크기 키우고, 팀명은 굵게 해줘
```

```
두 번째 슬라이드 카드 3개 간격 균등하게 맞춰줘
```

---

### Step 4 — 이미지/PDF로 내보내기

```
현재 디자인 PNG로 내보내줘
```

```
모든 슬라이드 PDF로 내보내줘
```

내보낸 파일은 발표 최종 PDF 취합 시 삽입합니다.

## 팀 협업 규칙

| 규칙 | 이유 |
|------|------|
| `.pen` 파일은 Claude Code에서만 열기 | 일반 편집기로 열면 암호화된 내용이라 읽히지 않음 |
| 완성본은 PNG/PDF로 내보낸 후 Google Drive 업로드 | 팀원 공유는 내보낸 이미지 기준 |
| 파일명 규칙: `slide_섹션명_v버전.pen` | 예: `slide_cover_v1.pen`, `slide_rfm_v2.pen` |
| 작업 전 담당 섹션을 팀 채팅에 공유 | 슬라이드 중복 작업 방지 |

## 토큰 사용량 안내

### 설치 단계에서는 토큰 소모 없음

Claude Code CLI 설치 자체는 로컬 프로그램 설치라 토큰 0 소모.  
토큰이 쓰이는 건 **설치 후 실제 Pencil MCP 도구를 호출할 때**부터입니다.

---

### 작업별 예상 토큰량

| 작업 | 토큰 소모 | 이유 |
|------|---------|------|
| 새 파일 열기 (`open_document`) | 낮음 ~500 | 단순 파일 오픈 |
| 현재 상태 읽기 (`get_editor_state`) | 낮음 ~1,000 | 캔버스 메타 정보 |
| 디자인 가이드 로드 (`get_guidelines`) | **높음 ~5,000** | 디자인 규칙 전체 로드 |
| 슬라이드 1장 생성 (`batch_design`) | 중간 ~3,000–6,000 | 요소 수·복잡도에 비례 |
| 기존 요소 읽기 (`batch_get`) | 중간 ~2,000–4,000 | 노드 수에 비례 |
| 스크린샷 (`get_screenshot`) | **매우 높음 ~8,000+** | base64 이미지 데이터 포함 |
| 전체 슬라이드 수정 (색상·폰트 일괄) | 중간 ~4,000 | 오퍼레이션 수에 비례 |

> Claude Sonnet 컨텍스트 창: **200K 토큰**  
> 슬라이드 1장 만들기 = 대략 5,000~10,000 토큰 → **1개 대화에서 8~10장 작업 가능**

---

### 토큰 절약 팁 (팀 권장)

**1. 슬라이드는 섹션 단위로 나눠서 작업**
```
한 대화(세션)에서 슬라이드 2~3장씩만 → 새 대화에서 이어가기
```

**2. 스크린샷 요청 최소화**
```
# 토큰 많이 씀 (피하기)
"슬라이드 스크린샷 보여줘"

# 대신 이렇게
"슬라이드 만들면 바로 PNG로 저장해줘" (화면 출력 없이 저장만)
```

**3. 가이드라인은 처음 한 번만 로드**
```
# 세션 시작 시 1회만
"Pencil 디자인 가이드라인 로드해줘"

# 이후 같은 세션에서는 다시 요청 X
```

**4. batch_design은 한 번에 묶어서**
```
# 비효율 (토큰 3배 소모)
"제목 색 바꿔줘" → "폰트 키워줘" → "배경 바꿔줘" (3번 호출)

# 효율적 (토큰 1번 소모)
"제목 색 #1B2A4A로, 폰트 32pt로, 배경 흰색으로 한 번에 바꿔줘"
```

**5. 슬라이드 개수별 권장 세션 분리**

| 총 슬라이드 수 | 권장 세션 분리 |
|-------------|-------------|
| 1~3장 | 1개 대화에서 완성 |
| 4~6장 | 2개 대화로 나누기 |
| 7~9장 (우리 팀 분량) | 3개 대화로 나누기 |

## 문제 해결

| 증상 | 해결 방법 |
|------|---------|
| "pencil 서버를 찾을 수 없음" | Claude Code 재시작 후 MCP 연결 재확인 |
| 디자인이 생성되지 않음 | 더 구체적으로 요청 (크기, 색상, 텍스트 내용 명시) |
| .pen 파일이 깨져 보임 | 일반 편집기로 열지 말 것 — Claude Code에서만 열기 |
| 내보내기 파일 저장 위치 모름 | 프로젝트 폴더 내 `exports/` 또는 작업 디렉토리 확인 |
