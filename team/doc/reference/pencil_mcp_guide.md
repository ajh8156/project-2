# Pencil MCP 팀원 공유 가이드

**대상**: 데2터로말해조 팀원 전체  
**목적**: Claude Code + Pencil MCP로 발표 슬라이드 및 카드뉴스 제작  
**작성일**: 2026-04-18

---

## 사전 준비 (팀원 각자 설치 필요)

### 1. Claude Code CLI 설치

1. 브라우저에서 https://claude.ai/code 접속
2. 본인 OS에 맞는 설치 파일 다운로드 (Windows / Mac)
3. 설치 완료 후 터미널(또는 PowerShell) 실행
4. 아래 명령어로 설치 확인:

```bash
claude --version
```

정상 출력 예시: `claude 1.x.x`

---

### 2. Pencil MCP 연동 확인

1. Claude Code 실행 (`claude` 명령어 입력 또는 데스크탑 앱 실행)
2. 채팅창 하단 또는 설정에서 **MCP 서버 목록** 확인
3. `pencil` 항목이 **연결됨(Connected)** 상태인지 확인
4. 연결 안 됨 표시 시 → 팀장(아무래도 아는 사람)에게 문의

---

## 기본 사용법

### Step 1 — 새 디자인 파일 열기

Claude Code 채팅창에 아래처럼 입력:

```
Pencil MCP로 새 디자인 파일 열어줘
```

또는 기존 파일을 이어서 작업할 때:

```
team/seller_ops/pencil-new.pen 파일 열어줘
```

---

### Step 2 — 슬라이드 생성 요청

자연어로 요청하면 Pencil이 디자인을 생성합니다.

**표지 슬라이드 예시:**
```
발표 슬라이드 표지 만들어줘.
- 팀명: 데2터로말해조
- 주제: Olist 데이터 기반 재구매 구조 전환 전략
- 스타일: 깔끔한 비즈니스 톤, 네이비 계열 컬러
- 하단에 날짜(2026-05-09)와 팀원 이름 칸 추가
```

**내용 슬라이드 예시:**
```
두 번째 슬라이드: 문제 정의 섹션 만들어줘.
- 제목: "왜 재구매율이 낮은가?"
- 핵심 지표 3개를 카드 형태로 배치:
  1. 재구매율 3% (업계 평균 대비 낮음)
  2. 평균 주문 1.03회
  3. 저평점(1-2점) 비중 15%
- 색상: 문제를 강조하는 레드 포인트 컬러
```

**차트/분석 슬라이드 예시:**
```
세 번째 슬라이드: RFM 세그먼트 결과 슬라이드 만들어줘.
- 제목: "고객 세그먼트 분석 결과"
- 4개 그룹(Champions / Loyal / At Risk / Lost)을 2x2 그리드로 배치
- 각 그룹에 고객 수와 특징 텍스트 포함
```

### Step 3 — 수정 요청

```
첫 번째 슬라이드 배경색을 #1B2A4A(진한 네이비)로 바꿔줘
```

```
표지 폰트 크기 키우고, 팀명은 굵게 해줘
```

```
두 번째 슬라이드 카드 3개 간격 균등하게 맞춰줘
```

### Step 4 — 이미지/PDF로 내보내기

```
현재 디자인 PNG로 내보내줘
```

```
모든 슬라이드 PDF로 내보내줘
```

내보낸 파일은 발표 최종 PDF 취합 시 삽입합니다.

## 팀 협업 규칙

| 규칙 | 이유 |
|------|------|
| `.pen` 파일은 Claude Code에서만 열기 | 일반 편집기로 열면 암호화된 내용이라 읽히지 않음 |
| 완성본은 PNG/PDF로 내보낸 후 Google Drive 업로드 | 팀원 공유는 내보낸 이미지 기준 |
| 파일명 규칙: `slide_섹션명_v버전.pen` | 예: `slide_cover_v1.pen`, `slide_rfm_v2.pen` |
| 작업 전 팀장에게 어느 섹션 담당인지 공유 | 슬라이드 중복 작업 방지 |

```
# 슬라이드 전체 구조 한 번에 잡기

섹션: 표지 / 문제정의 / 데이터구조 / 분석결과 / 인사이트 / Action Plan / 결론 / 회고
각 슬라이드는 16:9 비율, 비즈니스 톤 유지

# 차트 이미지 삽입
[분석 결과 이미지 경로] 이미지를 슬라이드 중앙에 배치하고
하단에 "출처: Olist 데이터 분석 결과" 캡션 추가해줘

# 컬러 통일
모든 슬라이드 제목 색상을 #1B2A4A로 통일해줘
강조 포인트 컬러는 #E85D26으로 설정해줘
```

## 문제 해결

| 증상 | 해결 방법 |
|------|---------|
| "pencil 서버를 찾을 수 없음" | Claude Code 재시작 후 MCP 연결 재확인 |
| 디자인이 생성되지 않음 | 더 구체적으로 요청 (크기, 색상, 텍스트 내용 명시) |
| .pen 파일이 깨져 보임 | 일반 편집기로 열지 말 것 — Claude Code에서만 열기 |
| 내보내기 파일 저장 위치 모름 | 프로젝트 폴더 내 `exports/` 또는 작업 디렉토리 확인 |
