## Claude 스킬 추천 (팀 4회 워크샵 외 자율 학습)

### 즉시 활용 (지금 시작)

| 스킬 | 사용법 | 효과 |
|------|-------|------|
| **Projects 기능** | Claude.ai에서 팀 프로젝트 생성 → 공통 문서(OKR, 데이터 정의) 업로드 | 매번 컨텍스트 반복 설명 불필요 |
| **시스템 프롬프트** | "나는 데이터 분석가야. SQL 전문가처럼 쿼리를 작성해줘" | 역할별 맞춤 응답 |
| **파일 업로드 분석** | CSV 파일 직접 업로드 → "이 데이터로 RFM 분석 해줘" | Python 코드 없이 즉시 분석 가능 |
| **이미지 분석(Vision)** | 루커 스크린샷 업로드 → "이 차트의 문제점은?" | 대시보드 피드백 자동화 |

### 중급 활용 (4/25 이후)

| 스킬 | 사용법 | 효과 |
|------|-------|------|
| **Pencil MCP** | Claude Code에서 디자인 명령 → 카드뉴스/슬라이드 생성 | 디자인 리소스 없이 시안 제작 |
| **Chain of Thought** | "단계별로 생각해서 이 분석 결과를 해석해줘" | 분석 논리 강화 |
| **역할 지정 프롬프팅** | "McKinsey 컨설턴트 관점에서 Action Plan을 검토해줘" | 발표 완성도 향상 |
| **HTML 슬라이드 생성** | "이 내용을 Reveal.js 슬라이드로 만들어줘" | 발표 자료 빠른 초안 |

### 고급 활용 (5/1 이후, 여유 시 도전)

| 스킬 | 사용법 | 효과 |
|------|-------|------|
| **프롬프트 체이닝** | 분석 → 요약 → 발표문 → Q&A 단계별 자동 생성 | 발표 자료 파이프라인 자동화 |
| **Claude API** | claude-sonnet-4-6 모델로 Q&A 시뮬레이터 간단 구현 | 발표 예상 질문 대비 자동화 |
| **Gmail MCP** | 팀 일정 및 파일 공유 자동화 | 협업 효율화 |
