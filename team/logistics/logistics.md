## Olist 배송 구조 분석

1. 셀러(Seller)마다 고유한 물리적 출발지가 다름
olist_sellers_dataset.csv 파일을 확인해 보시면, 3,000개가 넘는 셀러들의 고유한 seller_zip_code_prefix(우편번호)와 seller_city(도시) 데이터가 존재합니다.
만약 쿠팡 로켓배송처럼 중앙 물류센터 모델이라면, 출고지 주소는 Olist의 메가 물류센터가 위치한 몇 개의 우편번호로 통일되어야 합니다. 하지만 이 데이터는 물건이 브라질 전역에 흩어진 수많은 개별 상인들의 가게에서 각각 출발한다는 것을 증명합니다.

2. 하나의 주문에 각각 다른 배송비가 청구됨 (합포장 불가)
olist_order_items_dataset.csv 파일을 분석해 보면, 한 명의 고객이 한 번의 주문(order_id)으로 2개의 물건을 장바구니에 담아 결제했을 때, 그 물건들의 판매자(seller_id)가 다르면 **각각 별도의 배송비(freight_value)**가 부과된 것을 볼 수 있습니다.
중앙 창고에서 하나의 박스에 합포장(Kitting)되어 나가는 구조가 아니라, 각 판매자가 자신의 지역에서 개별적으로 택배를 부치기 때문에 발생하는 전형적인 오픈마켓 현상입니다.

3. 출고 리드타임의 극단적인 편차
olist_orders_dataset.csv의 시간 데이터를 보면, 결제 완료(order_approved_at) 후 택배사로 물건이 넘어가는 시간(order_delivered_carrier_date)이 주문마다 천차만별입니다. 어떤 건은 1일 만에 택배사로 넘어가지만, 어떤 건은 판매자가 게을러서 10일 넘게 쥐고 있습니다.
시스템화된 자체 물류센터(Fulfillment)를 굴리는 기업의 데이터에서는 출고 지연 시간이 이렇게 셀러별로 중구난방으로 튀지 않습니다.

4. 캐글(Kaggle) Olist 공식 데이터 소개문
이 데이터를 캐글에 공개한 Olist 본사의 공식 Description을 보면 비즈니스 모델이 정확히 명시되어 있습니다.

"Olist connects small businesses from all over Brazil to channels without hassle... Once the merchant is notified about the order, the seller prepares the package for shipping, and then it is delivered."
(Olist는 브라질 전역의 소상공인들을 연결합니다... 주문 알림을 받으면, 판매자가 직접 포장을 준비하고 배송됩니다.)

## Executive Summary

블랙프라이데이를 앞둔 현시점, Olist의 가장 큰 과제는 **"매출은 올리되, 재구매로 연결하지 못하는 구조"** 를 깨는 것이다.

데이터가 말하는 현실은 냉정하다.

- 저평점(1~2점) 리뷰 14,575건 분석 결과, **불만 원인 1위는 미배송(42.0%)**, 2위는 CS 무응답(19.8%)으로 물류가 고객 이탈의 핵심이다.
- 배송이 지연될 경우 저평점 비율은 **54%** — 정시 배송 대비 5.9배 높다.
- 재구매율은 **단 3%** 수준이다.

블랙프라이데이는 단기 매출의 기회이기도 하지만, **물류가 터지면 재구매를 영구적으로 잃는 위기**이기도 하다. 본 보고서는 이 구조를 깨기 위한 단기(3개월, 블랙프라이데이 대응) / 중기(6개월) / 장기(1년) 로드맵을 데이터 근거와 함께 제시한다.

## 1. 문제 진단 — 데이터가 드러낸 구조적 병목

### 1.1 리드타임 구조 분석

| 구간 | 평균 소요일 | 지연 시 소요일 | 비고 |
|---|---|---|---|
| Seller Lead Time (출고) | 2.8일 | ~3.7일 | 셀러 역량 의존 |
| Carrier Lead Time (배송) | 9.3일 | ~20.5일 | **병목의 핵심** |
| **Total Lead Time** | **12.1일** | **~24일** | 지연 시 2배 |

택배사 구간(Carrier)이 전체 리드타임의 77%를 차지하며, 지연 시 정상 대비 **2.5배** 증가한다. 그러나 근본 원인은 택배사가 아니라 **파편화된 셀러 출고 구조**에 있다. 브라질 전역에 흩어진 3,000개 이상의 셀러에서 개별 출고가 이뤄지기 때문에, 택배사의 집화 효율이 구조적으로 낮을 수밖에 없다.

### 1.2 고객 불만 원인 분해 (딥러닝 분류 기준, 10,611건)

| 불만 원인 | 비율 | 핵심 메시지 |
|---|---|---|
| **미배송** | **42.0%** | "아직도 안 왔다" — 계약 불이행 수준의 페인포인트 |
| 환불/CS 무응답 | 19.8% | 문제 발생 후 해결 경로 부재 |
| 배송 지연 | 8.7% | 지연 자체보다 사전 안내 부재가 더 큰 불만 |
| 제품 불량 | 9.2% | 셀러 품질 관리 미흡 |
| 기대 불일치 | 8.5% | 상품 정보와 실물의 괴리 |
| 포장 불량 | 5.5% | 장거리 배송 중 파손 |
| **가격/배송비** | **6.3%** | 신규 발견 — 다품목 구매 장벽 |

> **핵심 인사이트:** 배송이 정시에 도착했음에도 1점을 부여한 고객이 **6,122명** 존재한다. 배송만 개선해서는 저평점의 절반을 해결할 수 없다. 제품 품질, CS 대응, 정보 정확성을 함께 다뤄야 한다.

### 1.3 카테고리별 지연 현황 — 집중 관리 우선순위 도출

| 우선순위 | 카테고리 | 지연율 | 평균 지연 일수 | GMV | 전략 방향 |
|---|---|---|---|---|---|
| 🔴 긴급 | office_furniture | 15.01% | 15.1일 | 중 | 화물 전문 파트너 의무화 |
| 🔴 긴급 | furniture_bed_bath | 13.52% | 13.1일 | **최상** | 풀필먼트 우선 도입 대상 |
| 🟠 고위험 | health_beauty | 9.06% | 9.1일 | **최상** | **매출 1위 — 즉각 SLA 강화** |
| 🟠 고위험 | computers_accessories | 8위권 | 8~10일 | 상 | 정품 인증 + 전용 포장 |
| 🟡 관리 | watches_gifts | 중위권 | - | 상 | 고가 CS SLA 별도 설정 |

**health_beauty 집중 분석:**  
매출 1위 카테고리임에도 지연율 9.06%로 전체 9위권에 위치한다. 절대적인 주문량이 많기 때문에 이 지연율이 만들어내는 **불만 건수 자체가 플랫폼 전체 지연 불만의 대부분을 차지**한다. 지연율을 5%대로만 낮춰도 플랫폼 전체 신뢰도가 크게 회복될 수 있다.

## 2. 블랙프라이데이 특수 리스크 분석

2017년 블랙프라이데이 전후 데이터에서 확인된 패턴:

- 주문량 급증 시점과 지연률 급등이 **강하게 연동**된다.
- 물류 센터 처리 용량이 계절 수요를 따라가지 못하는 **구조적 임계점**이 존재한다.
- 블랙프라이데이 직후 불만족 리뷰가 **월 단위 최고치**를 기록하는 패턴이 반복된다.

**2018년 블랙프라이데이의 위험 시나리오:**  
셀러 파편화 구조 + 물동량 급증 → 택배사 집화 지연 → Carrier Lead Time 폭증 → 대규모 미배송·지연 리뷰 → 재구매 이탈

이를 방어하는 것이 이번 전략의 핵심이다.

## 3. 단기 전략 (D-Day ~ 3개월 / 블랙프라이데이 대응)

> **목표:** 블랙프라이데이 기간 배송 지연률 억제 + 불만 리뷰 최소화 + 재구매 씨앗 심기

### 3-1. 셀러 SLA 이원화 즉시 시행

**문제 근거:** 악성 셀러(상위 10%) 평균 출고 지연 11.7일, 지연 발생 확률 14.2% (일반 셀러 7.5%의 2배)

**실행 방안:**

- **Fast-Ship 인증제 즉시 도입**
  - 기준: 주문 알림 후 T+1일 이내 출고 완료
  - 혜택: 블랙프라이데이 기간 검색 상단 노출 우선권, 정산 주기 단축 (14일 → 7일)
  - 시각적 배지: 상품 페이지에 'Fast-Ship' 인증 뱃지 노출 → 구매 전환율 제고

- **악성 셀러 페널티 즉각 적용**
  - T+5일 초과 출고 셀러: 자동 경고 + 검색 노출 랭킹 하락
  - 블랙프라이데이 기간 중 T+3일 초과 시 임시 판매 중단

### 3-2. 피크 시즌 사전 재고 입고 캠페인

**문제 근거:** 블랙프라이데이 전후 지연률 급등 패턴 확인

**실행 방안:**

- 블랙프라이데이 **2~3주 전** 셀러 대상 긴급 캠페인 시행
  - 타깃: health_beauty, furniture_bed_bath, computers_accessories 셀러 우선
  - 인센티브: 사전 입고 완료 셀러에게 블랙프라이데이 기간 수수료 1% 우대
  - 결과: 피크 시점 Seller Lead Time → 0일, 주문 즉시 택배사 인도 가능

- 협력 택배사와 **집화 물량 사전 계약** (피크 기간 우선 집화 SLA 체결)

### 3-3. 고위험 카테고리 즉각 대응

| 카테고리 | 즉시 조치 |
|---|---|
| health_beauty | CS 전담 인력 2배 증원, 지연 발생 즉시 자동 알림 발송 |
| office_furniture | 화물 전문 택배사 별도 연결 의무화 |
| computers_accessories | '정품 인증 셀러' 뱃지 도입, 발송 전 실물 사진 공유 |
| watches_gifts (고가) | 고가 주문 전담 CS팀 배정, 4시간 내 응답 SLA |

### 3-4. 선제적 고객 커뮤니케이션 강화

**문제 근거:** TF-IDF 분석 키워드 'ainda(아직)', 'aguardando(기다리는 중)' — 안내 부재가 불만을 키움

**실행 방안:**

- 지연 감지 시 **고객이 클레임 전에** 사과 + 예상 배송일 업데이트 자동 발송
- 블랙프라이데이 주문 전 배송 예상일을 현실적으로 고지 (기대치 선제 관리)
- 지연 7일 초과 시 자동 배상 쿠폰 발행 (운송비 환불 또는 다음 구매 할인)

### 3-5. 재구매 연결 장치 — 블랙프라이데이 직후

**목표:** 이벤트 구매자를 재구매 고객으로 전환

- 배송 완료 후 **3일 이내** 만족도 설문 + 재구매 쿠폰 발송 (유효기간 30일)
- 1~2점 리뷰 작성 고객 대상: **24시간 이내** 1:1 사과 메시지 + 즉시 사용 가능 할인 쿠폰
- Fast-Ship 셀러 구매 고객에게 '다음 구매 시 해당 셀러 Fast-Ship 우선 매칭' 알림

## 4. 중기 전략 (3~6개월)

> **목표:** 물류 품질 구조 개선 + 카테고리별 특화 대응 + CS 시스템 고도화

### 4-1. 지역별 특화 3PL 파트너십 구축

**문제 근거:** 지역별 지연 비중이 뚜렷하게 차이남 — 외곽(북부/북동부) 지역은 지리적 거리가 주요 원인

**실행 방안:**

- **고지연 지역:** 직접 투자 없이 현지 3PL 파트너와 계약
  - 피크 시즌 전 임시 창고 단기 임차로 재고 사전 분산 배치
  - 해당 지역 고객에게는 배송 예상일을 현실적으로 더 길게 고지 (기대치 조정)

- **주요 거점(SP, MG, RJ):** 택배사 집화 밀도 강화 + Fast-Ship 셀러 집중 육성

- **지역 SLA 차등 적용:** 브라질리아 이북 지역은 배송 SLA 기준 자체를 현실적으로 조정하여 불필요한 지연 분류 감소

### 4-2. 카테고리별 특화 물류 설계

**가구 카테고리 (office_furniture, furniture_bed_bath) — 지연율 최상위**
- 화물 전문 택배사와의 파트너십 의무화 (일반 택배 불가 기준 상품 분류)
- 부피/중량 기반 자동 출고 경로 배정 시스템 도입
- 조립·설치 서비스 연계로 '배송+서비스' 번들 차별화

**health_beauty — 매출 1위, 즉각 개선 필요**
- Olist 풀필먼트 센터 도입 1순위 카테고리로 지정
- 목표: 지연율 9.06% → 5%대로 인하 (절대 지연 건수 약 40% 감소 효과)

**computers_accessories — 정품 의심 불만 다수**
- 셀러 정품 인증 제도 도입 (키워드 'original' 반복 불만 해소)
- 고가 IT 기기 특별 포장 서비스 + 발송 전 실물 검수 사진 공유

### 4-3. 데이터 기반 CS 시스템 고도화

**문제 근거:** 딥러닝 분류에서 확인된 불만 유형별 대응 시나리오 부재

**실행 방안:**

- 불만 유형 자동 분류 AI 엔진 도입 (미배송 / CS무응답 / 제품불량 / 기대불일치)
- 유형별 최적화된 보상 시나리오 자동 실행 시스템 구축
- watches_gifts 등 고가 카테고리: Post-Purchase CS SLA 별도 설정 (4시간 응답 → 1시간)

### 4-4. 배송비 구조 개선 — 다품목 구매 유도

**문제 근거:** 딥러닝 분류에서 신규 발견된 배송비 불만 679건(6.3%) — "다품목 사도 배송비가 더 비싸진다"

**현황:** 평균 Items/Order = 1.14개 (단품 위주)

**실행 방안:**

- 동일 셀러 내 2개 이상 구매 시 배송비 무료 또는 할인 정책 도입
- 번들 구매 유도 UI: "이 셀러의 상품 추가 시 배송비 무료" 노출
- 합포장 가능 셀러 인증 뱃지 도입 → 구매 전환율 제고

---

## 5. 장기 전략 (6개월 ~ 1년)

> **목표:** 구조적 물류 혁신 + 풀필먼트 센터 구축 + 계절성 수요 완전 대응 체계

### 5-1. Olist Fulfillment 센터 전략적 구축

**핵심 원칙:** 잘 되는 곳(고물동량 거점)에 먼저 짓고, 느린 곳은 3PL로 관리한다.

**1단계: 상파울루(SP) 거점 우선 구축**
- 물동량 최대 + 택배사 네트워크 최밀집 → 센터 가동률 극대화
- health_beauty, furniture_bed_bath 재고 우선 입고
- 기대 효과: **Seller Lead Time → 0일**, 합포장 가능, 배송비 절감

**2단계: MG, RJ 거점 확장**
- SP 운영 데이터 기반으로 거점 위치 정밀 선정
- Fast-Ship 셀러 입고 인센티브 프로그램 연계

**기대 효과 요약:**
- 출고 리드타임 표준화 (셀러 역량 의존도 제거)
- 합포장으로 배송비 절감 → 다품목 구매 장벽 해소
- 택배사 집화 계약 효율 극대화 → Total Lead Time 30% 이상 단축 기대

### 5-2. 계절성 수요 완전 대응 체계 구축

**문제 근거:** 블랙프라이데이 전후 지연률 급등이 반복되는 구조적 패턴

**풀필먼트 센터 + 계절성 대응의 결합:**
- 블랙프라이데이 2~3주 전 **사전 입고 캠페인** (센터에 재고가 이미 있으므로 피크 시 셀러 변수 제거)
- 수요 예측 모델 도입: 전년도 동기 데이터 기반 카테고리별 재고 사전 배치
- 피크 2주 전부터 입고 우선순위를 회전율 높은 SKU 중심으로 자동 조정

**피크 버퍼 거점 운영:**
- 평소에는 거점이 없는 지역이라도 피크 시즌 전 3PL 단기 임차
- 연간 캘린더 기반 '위험 기간' 사전 예측 → CS 인력·물류 파트너 선제 확보

### 5-3. 악성 셀러 구조적 정화 — 장기 플랫폼 신뢰도 제고

**문제 근거:** 악성 셀러(상위 10%)가 전체 지연의 9.6% 유발, 개별 출고 지연 평균 11.7일

**장기 실행 방안:**
- 셀러 등급제 도입 (Gold / Silver / Standard / Warning)
- 등급별 검색 노출, 수수료율, 정산 주기 차등 적용
- Warning 등급 셀러: 분기별 개선 미확인 시 퇴출 프로세스 적용
- 신규 셀러 온보딩 시 물류 프로세스 교육 의무화

### 5-4. 상품 정보 품질 개선 — 기대 불일치 해소

**문제 근거:** bed_bath_table 색상·사이즈 불일치 불만 다수, 설명 길이 U자형 패턴 (너무 짧거나 너무 길 때 1점 비율 상승)

**실행 방안:**
- 카테고리별 최적화된 상품 등록 템플릿 의무화
- 가구 카테고리: 치수·소재·조립 여부 필수 기재 가이드
- bed_bath_table: 실제 색상 샘플 이미지 필수 등록
- 셀러 교육 콘텐츠: 상품 정보 품질이 리뷰 점수와 검색 랭킹에 미치는 영향 데이터 공유

## 6. 전략 로드맵 요약

```
[ 단기 — 블랙프라이데이 D-Day ~ 3개월 ]
  ├── 셀러 SLA 이원화 즉시 시행 (Fast-Ship / 악성 셀러 페널티)
  ├── 피크 시즌 사전 재고 입고 캠페인
  ├── 고위험 카테고리 즉각 대응 (health_beauty, furniture, computers)
  ├── 선제적 고객 커뮤니케이션 (지연 자동 알림 / 기대치 관리)
  └── 재구매 연결 장치 (배송 완료 후 쿠폰 + 1~2점 리뷰 즉각 대응)

[ 중기 — 3~6개월 ]
  ├── 지역별 특화 3PL 파트너십 구축
  ├── 카테고리별 특화 물류 설계 (가구 전용 / health_beauty 전담)
  ├── 데이터 기반 CS 자동화 시스템
  └── 배송비 구조 개선 (다품목 구매 유도)

[ 장기 — 6개월 ~ 1년 ]
  ├── Olist Fulfillment 센터 구축 (SP 우선 → MG, RJ 확장)
  ├── 계절성 수요 완전 대응 체계 (수요 예측 + 사전 입고)
  ├── 악성 셀러 구조적 정화 (등급제 + 퇴출 프로세스)
  └── 상품 정보 품질 개선 (카테고리별 등록 템플릿 의무화)
```

## 8. 결론

Olist의 물류 문제는 단순한 배송 속도 문제가 아니다. **셀러 파편화 → 출고 불확실성 → 택배사 집화 비효율 → 고객 경험 손상 → 재구매 이탈**로 이어지는 구조적 연결고리가 핵심이다.

블랙프라이데이는 이 연결고리가 가장 강하게 작동하는 시점이다. 물량이 터질 때 구조가 버텨주지 못하면, 매출은 올라도 재구매는 영구적으로 잃는다.

본 보고서가 제안하는 전략의 핵심은 세 가지다.

1. **단기:** 지금 당장 실행 가능한 셀러 SLA 강화와 선제적 고객 커뮤니케이션으로 블랙프라이데이를 방어한다.
2. **중기:** 카테고리별 특화 대응과 3PL 파트너십으로 구조를 보완한다.
3. **장기:** 풀필먼트 센터로 셀러 변수를 제거하고, 계절성 수요에도 흔들리지 않는 물류 체계를 완성한다.

이 세 단계가 순서대로 실행될 때, Olist는 브라질에서 가장 신뢰받는 커머스 플랫폼으로 도약할 수 있다.
