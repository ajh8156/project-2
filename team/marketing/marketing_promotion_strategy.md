## 1. 전략 배경 — 2017 BF가 남긴 교훈

| 2017 BF 성과 | 수치 | 평가 |
|------------|------|-----|
| BF 당일 주문량 | 1,147건 (평시 **7.94배**) | ✅ 전환 자체는 강력 |
| BF cohort 재구매율 | **1.55%** (전체 평균의 절반) | 🚨 재구매 구조 실패 |
| BF 기간 배송 지연율 | **20.93%** (평시의 3배) | 🚨 경험 훼손 |
| BF 기간 AOV 변화 | **-10.1%** | ⚠️ 할인만 하고 객단가 빠짐 |
| BF 기간 다품목 비중 | +0.57%p (거의 변화 없음) | ⚠️ bundle 효과 없었음 |

### 2017 BF의 실패 구조

```
BF 트래픽 7.94배 폭증
        ↓
단순 % 할인 → AOV -10.1%
배송 물량 집중 → 지연율 20.93%
bundle 없음 → 다품목 변화 없음
        ↓
BF 첫 구매 경험 훼손
        ↓
BF cohort 재구매율 1.55% (평균의 절반)
        ↓
BF는 매출 스파이크만 만들고 끝
```

### 2018 BF 전략 목표

> **BF 트래픽은 유지하면서, 재구매 구조를 망가뜨리지 않는다**

## 2. 전략 핵심 원칙 3가지

### 원칙 1. 할인 구조를 % 할인 → threshold + bundle로 전환

| 방식 | 문제 | 대안 |
|-----|-----|-----|
| 단순 % 할인 | AOV -10.1%, 재구매 유인 없음 | BRL 120 무료배송 threshold |
| 전 카테고리 동일 할인 | 고가 상품 마진 훼손 | 카테고리별 차별화 |
| 당일 집중 | 배송 지연율 20.93% | 얼리버드로 물량 분산 |

**무료배송의 실제 가치:**
- 배송비 평균 BRL 22.78 = AOV의 14.3%
- 고객 체감으로는 14.3% 할인과 동일한 효과
- 하지만 실제 프로모션 비용은 BRL 22.78만 발생
- → **무료배송이 % 할인보다 비용 효율적인 레버**

### 원칙 2. BF 주력 카테고리를 bed_bath_table로 집중

| 지표 | bed_bath_table 성과 |
|-----|------------------|
| BF 반응 | 5.18x (전체 2위) |
| 재구매율 | **2.8%** (전체 1위) |
| **구매자 재구매율** | **6.42%** (전체 평균 3.00%의 2.1배) |
| co-purchase 조합 | 4개 조합 등장 (전체 1위) |
| 소모품 리필 패턴 | 273건 (공동 1위) |

> bed_bath_table 구매자는 다른 카테고리 구매자보다 재구매 가능성이 2배 높다.
> BF에서 이 카테고리 고객을 확보하는 것이 곧 재구매 cohort 확보다.

### 원칙 3. BF 당일 집중을 얼리버드로 분산시켜 배송 지연 완화

- 2017 BF 당일 피크: **저녁 22시** (하루 주문의 7.4%)
- 오전 집중 유도 + 얼리버드 분산 → 배송 처리 시간 확보
- 목표: BF 기간 지연율 20.93% → 15% 이하

### Phase 1 — 얼리버드 (D-7 ~ D-4, 11/16~11/19)

**목적:** 고가 상품 구매를 BF 전에 당기고, BF 당일 물량 집중 완화

**데이터 근거:** 2017 D-4(월요일) AOV BRL 224 — 분석 기간 중 최고점

#### 얼리버드 대상 카테고리 (고가 중심)

| 카테고리 | 평균 AOV | 얼리버드 할인 구조 |
|---------|---------|----------------|
| computers | BRL 1,380 | 무이자 12개월 할부 강조 |
| home_appliances_2 | BRL 515 | 무이자 6개월 + 무료배송 |
| office_furniture | BRL 382 | 무이자 6개월 + 무료배송 |
| watches_gifts | BRL 237 | 선물 포장 무료 + 5% 할인 |
| musical_instruments | BRL 340 | 무이자 6개월 |

> 얼리버드는 % 할인보다 **무이자 할부 + 무료배송** 조합을 기본 구조로.
> 신용카드 고객 76.6%, 평균 할부 3.5개월 → 무이자 6~12개월은 강력한 전환 유인.

#### 얼리버드 메시지 구조

```
"BF 전에 먼저 드립니다"
BF 기간보다 먼저 구매하면:
✅ 무이자 6개월 할부
✅ 무료배송
✅ 배송 지연 없이 BF 전 도착 보장
(BF 당일은 배송이 몰려 지연될 수 있습니다)
```

> BF 당일 배송 지연 우려를 역이용해 얼리버드 구매 동기 부여

### Phase 3 — BF 당일 (11/23, 금요일)

**목적:** 최대 전환 + AOV 방어 + 배송 물량 분산

**데이터 근거:**
- 2017 BF 피크: 저녁 22시 (7.4%) → 오전 집중 유도
- 오전(0~12시): 31.7% / 오후(12~24시): 68.3% → 오전 비중 높이기

#### 시간대별 BF 당일 운영

| 시간대 | 행사명 | 내용 |
|------|------|-----|
| **00:00 오픈** | BF 시작 | 전체 프로모션 오픈 알림 |
| **06:00~10:00** | 얼리모닝 특가 | bed_bath_table + bundle 10% 추가 할인 (오전 한정) |
| **10:00~14:00** | 메인 타임 | 홈/리빙 bundle + BRL 120 threshold 전면 노출 |
| **14:00~18:00** | 오후 특가 | 베이비/키즈 클러스터 집중 |
| **18:00~22:00** | 저녁 러시 | health_beauty + perfumery bundle |
| **22:00~23:59** | 라스트콜 | "BF 마감 X시간" — 미결제 장바구니 알림 |

> 오전 시간대 한정 추가 혜택을 줘서 주문을 앞으로 당김 → 배송 처리 시간 확보

#### BF 당일 핵심 프로모션 구조

**① BRL 120 무료배송 threshold (전 카테고리)**
```
BRL 120 이상 구매 → 무료배송
"BRL XX만 더 담으면 무료배송" 장바구니 배너 자동 노출
추천 상품: bed_bath_table 소모품 / health_beauty 리필
```

**② 홈/리빙 bundle (주력)**
```
[bundle A] bed_bath_table + housewares
→ 함께 구매 시 배송비 무료 + 추가 5% 할인

[bundle B] bed_bath_table + furniture_decor
→ 함께 구매 시 배송비 무료 + 추가 5% 할인

[bundle C] baby + toys
→ 선물 포장 무료 + 배송비 무료
```

**③ 소모품 동일 카테고리 2개+ 할인**
```
같은 카테고리 2개 이상 구매 시 추가 3% 할인
대상: bed_bath_table / health_beauty / housewares / sports_leisure
(소모품 리필 패턴 9.3% → 명시적 유도)
```

**④ 신용카드 무이자 할부 (고가 상품)**
```
BRL 300 이상: 무이자 6개월
BRL 500 이상: 무이자 10개월
대상: computers, home_appliances, office_furniture, watches_gifts
```

### Phase 4 — BF 이후 cohort 수확 (D+1 ~ D+30)

**목적:** BF 구매자를 재구매 cohort로 전환 (KR1 달성)

**데이터 근거:**
- 2017 BF cohort 재구매율: 1.55% → 목표 3.5%
- 이탈재구매자 재구매 중앙값: 29일 → D+30이 핵심 타이밍
- BF 이후 2주 일평균 300건 (평시 188건보다 높음) → 수요 지속

#### D+1 ~ D+7 (즉각 follow-up)

| 트리거 | 액션 | 담당 |
|------|-----|-----|
| BF 구매 완료 직후 | 온사이트 팝업: "다음 구매 BRL 15 쿠폰 (30일 유효)" | **프로모션팀** |
