# 셀러 성과 관리 프레임워크

> 작성일: 2026-04-11
> 오너: Seller Ops (TF4 리드)
> 협업: 물류팀 (배송 성과 데이터 제공 / Fast-Ship 기술 판정)
> 목적: 셀러 등급·SLA·인센티브·페널티를 하나의 체계로 통합해 전사 재구매율 개선에 기여

---

## 1. 프레임워크 개요

```
셀러 성과 측정
      │
      ▼
  등급 분류 (S / A / B / C)
      │
      ├─ 상위 등급 → 인센티브 (수수료 우대 / 노출 우선 / VIP 지원)
      └─ 하위 등급 → 경고 → SLA 강화 → 페널티 (노출 제한 / 계약 종료)
```

**설계 원칙**
- 배송 품질과 리뷰 점수가 재구매율에 직결된다는 데이터 근거에 기반
- 페널티보다 인센티브를 앞세워 셀러 자발적 개선을 유도
- 물류팀과 기준 통합 → Seller Ops(출고 귀책)와 물류(전체 배송)를 분리 관리

---

## 2. 핵심 성과 지표 (KPI)

| 지표 | 정의 | 데이터 소스 | 집계 주기 |
|------|------|-----------|---------|
| 셀러 귀책 배송 지연율 | order_delivered_customer_date > order_estimated_delivery_date 중 출고 지연 귀책 비율 | olist_orders + 물류팀 귀책 판정 | 월별 |
| 평균 리뷰 점수 | 해당 셀러 delivered order의 review_score 평균 | olist_order_reviews | 월별 |
| 1점 리뷰 비율 | 전체 리뷰 중 1점 비율 | olist_order_reviews | 월별 |
| Activation Rate | 계약 후 90일 이내 첫 delivered order 발생 비율 | olist_orders + closed_deals | 분기별 |
| 첫 판매 소요일 | won_date → 첫 delivered order 날짜 (중앙값) | olist_orders + closed_deals | 분기별 |
| GMV 기여 비중 | 셀러별 price + freight_value 합계 / 전체 GMV | olist_order_items | 분기별 |

## 3. 셀러 등급 체계

> 배송 지연율과 리뷰 점수 두 축으로 등급을 결정한다.
> 매 분기 말 산정 → 익 분기 적용.

| 등급 | 기준 | 해당 셀러 규모 (현황) |
|------|------|------------------|
| **S** (VIP) | 지연율 5% 미만 + 리뷰 4.3점 이상 | 상위 GMV Top100 기준 관리 |
| **A** (우수) | 지연율 5~10% 미만 + 리뷰 4.0점 이상 | |
| **B** (일반) | 지연율 10% 미만 또는 리뷰 3.8점 이상 | |
| **C** (관리 대상) | 지연율 10% 이상 또는 리뷰 3.8점 미만 | 현재 지연율 상위 10% 약 300명 |

**현황 근거**
- 지연율 0~5% 셀러 평균 리뷰: **4.23점**
- 지연율 30%+ 셀러 평균 리뷰: **3.42점** (격차 0.81점)
- Top100 중 4.0점 미만 위험 셀러: **23명(23%)**

## 4. SLA 기준

### 4-1. 출고 SLA (셀러 귀책 기준)

| 구분 | 기준 | 비고 |
|------|------|------|
| 표준 출고 기한 | 주문 확정 후 **2영업일** 이내 출고 | 계약서 필수 동의 항목 |
| 배송일 buffer 의무 | 지연율 10%+ 셀러는 예상 배송일 **+1~2일** 설정 의무 | 9월 착수 시 즉시 적용 |
| 심각 지연 기준 | 예상 배송일 대비 **7일 초과** | 현황: 전체의 3.47% |

### 4-2. 상품 등록 SLA (온보딩)

| 구분 | 기준 |
|------|------|
| 내부 심사 완료 | 상품 등록 후 **3영업일** 이내 |
| 첫 판매 목표 | 계약 완료 후 **25일** 이내 (현황 중앙값 44일) |

### 4-3. 리뷰 품질 SLA

| 구분 | 기준 |
|------|------|
| 최소 유지 기준 | 평균 리뷰 점수 **3.8점** 이상 |
| VIP 유지 기준 | 평균 리뷰 점수 **4.3점** 이상 |
| 위험 기준 | 1점 리뷰 비율 **15%** 초과 시 즉시 코칭 대상 |

## 5. 경고 및 페널티

> 경고 → 개선 기회 부여 → 미개선 시 페널티 순서로 단계적 적용.

| 단계 | 발동 조건 | 조치 내용 |
|------|---------|---------|
| **1차 경고** | 지연율 10% 초과 또는 리뷰 3.8점 미만 (1개월) | 경고 메일 발송 + 개선 가이드 제공 |
| **2차 경고** | 동일 기준 2개월 연속 | 전담 담당자 1:1 코칭 + 개선 계획서 제출 요구 |
| **노출 제한** | 지연율 10% 초과 **3개월 연속** | 신규 상품 노출 제한 + 프로모션 참여 제외 |
| **입점 유지 재심사** | 지연율 20% 초과 또는 리뷰 3.5점 미만 **6개월** | 계약 유지 여부 재심사 |
| **계약 종료** | 재심사 후 개선 미흡 | 계약 자동 종료 (1년 목표 시점 계약서 조항 명시 예정) |

## 6. 인센티브

> 상위 등급 셀러의 이탈 방지 + 하위 등급 셀러의 자발적 개선 유도.

| 인센티브 | 대상 | 내용 |
|---------|------|------|
| 수수료 우대 | S등급 / 재구매 친화 카테고리 셀러 | 수수료 한시 감면 (비율은 재무팀 협의) |
| 노출 우선권 | S·A등급 | 검색 및 카테고리 상단 노출 우선 적용 |
| VIP 전담 지원 | Top100 S등급 | 전담 account manager 배정 + 월 1회 정기 컨택 |
| 프로모션 우선 참여 | S·A등급 | BF·시즌 프로모션 우선 초대 |
| Fast-Ship 인증 | 지연율 3% 미만 + 물류팀 기술 판정 통과 | 상품 페이지 인증 배지 노출 |
| 재활성화 우대 | 휴면 셀러 복귀 시 | 수수료 한시 우대 + 재입점 가이드 제공 (KR6 연계) |

## 7. 운영 프로세스

### 월별 루틴

```
매월 1일
  → 전월 배송 성과 데이터 수신 (물류팀)
  → 셀러별 지연율·리뷰 점수 집계
  → C등급 셀러 경고 발송
  → 배송 성과 리포트 자동 발송 (전 셀러)

매월 15일
  → 위험 셀러 (2차 경고 이상) 1:1 코칭 진행
  → Top100 모니터링 리포트 검토
```

### 분기별 루틴

```
분기 말
  → 등급 재산정 및 익 분기 적용
  → 인센티브·페널티 조치 실행
  → 성과 리뷰 미팅 (Top100 셀러 대상)
  → TF4 물류팀 합동 검토 (기준 정합성 확인)
```

## 8. TF4 물류팀 역할 분담

| 영역 | Seller Ops (오너) | 물류팀 (지원) |
|------|-----------------|------------|
| 등급 기준 설계 | 프레임워크 설계 + 집행 | 배송 성과 데이터 제공 |
| SLA 기준 | 출고 귀책 SLA 확정 + 경고/페널티 | Fast-Ship 인증 기술 판정 |
| 셀러 교육 | 교육 콘텐츠 제작 + 실행 | 카테고리별 불만 데이터 제공 |
| 북동부 확장 | 셀러 유치 실행 | 3PL 계약 (선행 조건) |

> **원칙**: 출고 귀책(셀러 측)과 배송 귀책(물류 측)을 명확히 분리해 측정. 모호한 건은 TF4 합동 판정.
