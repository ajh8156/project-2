> **작성일**: 2026-05-01  
> **목적**: BF 번들 기획 + 무료 배송 정책 경영진 의사결정 지원  
> **수치 기준**: CSV 실측 + integrated_okr_plan.md SSoT (BRL 1 = ₩302)

---

## 핵심 전제

**Olist 구조상 동일 셀러 주문은 배송비 1개** (CSV freight_value 확인 완료)

고객이 같은 셀러에서 2개를 사도, 다른 셀러에서 각 1개씩 사도 배송비는 셀러당 1개씩 부과된다.  
→ 번들의 가치는 **할인 + 배송비 무료**의 조합에서 나온다.

## #1. 번들 할인율과 무료 배송 설계

### 할인율 시나리오 (3가지)

> **가정**: BF 주간 주문 ~2,220건 (정상 1,110건 × 2배, 업계 벤치마크)  
> **2차 아이템 단가**: ₩30,000 (보수적 추정)  
> **배송비**: BRL 22.78 ≈ ₩6,880

| | **10% 할인** | **15% 할인 ★권고** | **18% 할인** |
|---|---|---|---|
| 고객 체감 | 약함 (배송비 무료가 주된 유인) | 균형 (할인 + 배송비 무료 = 명확한 혜택) | 강함 (가격 경쟁력 최대) |
| 다품목 전환 예상 | +1.5%p → **9.98% → 11.5%** | +3.5%p → **9.98% → 13.5%** ✅ | +5.5%p → **9.98% → 15.5%** |
| BF 추가 번들 주문 | ~33건 | ~78건 | ~122건 |
| 추가 GMV (2차 아이템) | ₩99만 | **₩234만** | ₩367만 |
| Olist 배송비 부담 | 33건 × ₩6,880 = **₩23만** | 78건 × ₩6,880 = **₩54만** | 122건 × ₩6,880 = **₩84만** |
| **GMV / 배송비 비용 ROI** | **4.3배** | **4.3배** | **4.4배** |
| BF-KR2 (13~14%) 달성 | ❌ 미달 | ✅ 달성 | ✅ 초과 |

> **15% 권고 이유**: ROI는 세 옵션 모두 4.3~4.4배로 동일하나, BF-KR2 목표(13~14%) 달성은 15% 이상에서만 가능. 18%는 달성 가능성 높지만 셀러 마진 저항이 커서 참여율 저하 위험.

### 셀러 설득 논거

> 셀러 입장에서 "내가 왜 15% 할인을 해줘야 하나?"에 대한 답

**셀러 손익 계산 (번들 1건당):**

| 항목 | 수치 |
|------|------|
| 2차 아이템 추가 판매 (안 팔렸을 수도 있던 재고) | +₩30,000 |
| 번들 할인 15% 부담 (2차 아이템 기준) | -₩4,500 |
| 배송비: Olist 부담 → **셀러 0원** | ₩0 |
| **셀러 순 추가 수익** | **+₩25,500** |

→ **셀러는 할인을 제공하지만, 불확실했던 재고 판매가 +₩25,500 확정 수익으로 전환된다.**

**추가 인센티브 (Olist 제공):**
- 번들 상품 BF 메인 배너 + 카테고리 상단 우선 노출
- Fast-Ship 인증 가점 (검색 상위 노출 + 신뢰 배지)
- BF 종료 후 전환율 상위 번들 → 상시 상품 우선 등록권

### Olist 경영진 설득: 배송비 부담의 근거

**단기 ROI (BF 1주):**

| 항목 | 수치 |
|------|------|
| Olist 배송비 부담 | ₩54만 |
| 번들로 발생하는 추가 GMV | ₩234만 |
| **ROI** | **4.3배** |

**중·장기 비즈니스 임팩트:**

| 임팩트 | 내용 | KR 연결 |
|--------|------|---------|
| **BF cohort 품질 향상** | 번들 구매자는 다품목 구매 경험 → 재구매 가능성 높음. BF cohort 30일 재구매율 0.56% → 1.5~2.0% | KR1 재구매율 |
| **AOV 방어** | BF 2017 AOV -10.1% 재현 방지. 번들 구조로 ₩51,340 유지 | BF-KR3 |
| **배송비 불만 679건 해소** | 저평점 원인 중 6.3%를 차지하는 배송비 불만 구조적 해소 | KR5 간접 |
| **번들 검증 → 중기 상시화** | BF 실험 결과로 상위 5개 번들 상시화 → 월 다품목 비중 지속 상승 | KR2·KR3 |
| **Olist 비용 규모** | BF 1주 ₩54만, 상시화 시 월 ~₩200만 | 배송비 ROI 4.3배 유지 전제 |

## #2. 적용 범위: 특정 카테고리 vs 동일 셀러 전체

### 시나리오 A. 특정 카테고리 번들 지정

> MD팀이 사전 기획한 10개 번들 상품에만 적용

**예시 대상:**  
`cama_mesa_banho` (침대·침구·욕실) Top2 1,045건 기반 → 침실 완성 세트, 홈케어 스타터 등

| 항목 | 내용 |
|------|------|
| 대상 범위 | MD 기획 번들 10개 (BF 준비 9~10월 셀러 협의 후) |
| BF 주간 예상 대상 주문 | ~78건 (다품목 비중 +3.5%p 기준) |
| Olist 배송비 부담 | **₩54만** (BF 1주) |
| 추가 GMV | **₩234만** |

**순기능:**
- Olist 비용 통제 가능 (대상이 제한됨)
- 번들 품질 보장 (MD가 셀러·상품 선별)
- Fast-Ship 셀러만 포함 → 배송 지연율 악화 방지
- 카테고리별 성과 측정 용이 → 중기 전략으로 데이터 전환 가능

**트레이드오프:**
- 셀러 협의 최소 6주 → **9월 착수 필수, 늦으면 BF 실행 불가**
- 10개 번들로 효과가 제한될 수 있음 (다품목 비중 목표 13~14% 달성 불확실)
- 카테고리 외 구매 고객은 혜택 제외 → UX 불공평 인식 가능

---

### 시나리오 B. 동일 셀러 2개 이상 구매 시 전면 적용

> 카테고리 관계없이, 같은 셀러에서 2개 이상 담으면 자동 무료 배송

| 항목 | 내용 |
|------|------|
| 대상 범위 | 동일 셀러 2개+ 주문 전체 (현재 8.67% = 8,360건/20개월) |
| BF 주간 예상 대상 주문 | ~244건 (BF 주간 2,220건 × 11% 추정) |
| Olist 배송비 부담 | **₩168만** (BF 1주) |
| 추가 GMV | 전환 증가분 추정 어려움 (번들 할인 없이 배송비만 무료) |

**순기능:**
- 셀러 협의 불필요 → **즉시 실행 가능**
- 적용 대상이 훨씬 넓음 → 다품목 비중 상승 속도 빠름
- 고객 UX 단순 ("같은 셀러에서 2개 이상 = 무료 배송")
- 자연 발생 수요(8.67%) 전부 흡수

**트레이드오프:**
- Olist 배송비 부담 3배 (₩54만 → ₩168만/BF주)
- 번들 할인 없음 → 신규 수요 창출력 약함 (기존 다품목 구매자 혜택만)
- 낮은 단가 상품 2개 주문으로 배송비 무료 받는 어뷰징 위험
- 카테고리 품질 통제 불가 (재고 소진용 저가 상품 번들 가능)
