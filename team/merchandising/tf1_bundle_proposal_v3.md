## 제안 배경

### 왜 지금인가

Olist에서 공식 번들 프로모션이 진행된 적이 없다. 할인도, 무료배송 연동도 없었다.  
그럼에도 불구하고 고객들은 **자연 발생적으로** 동일 셀러에서 2개 이상을 구매하고 있다.

| 지표 | 수치 | 의미 |
|------|------|------|
| 동일 셀러 다품목 주문 비율 | **9.01%** (8,692건) | 인센티브 없이도 자연 수요 존재 |
| 다품목 구매 셀러 수 | **1,363명 (45.9%)** | 번들 실행 가능한 셀러 기반 확보 |
| 동일 카테고리 내 구매 비율 | **97%** | 고객 구매 의도가 카테고리 단위로 집중 |
| BF 2017 다품목 비율 | **10.6%** | BF 시즌에도 자연 다품목 수요 존재 |

→ **인센티브가 생기면 이 수요가 폭발할 수 있는 잠재 시장이 이미 형성되어 있다.**

### 이번 BF 번들 기획전의 차별점

기존 BF와 다른 유일한 점:

| 기존 BF | 이번 BF 번들 기획전 |
|--------|------------------|
| 할인 없음 (또는 개별 상품 단순 할인) | **번들 할인 15%** |
| 배송비 고객 부담 | **무료 배송 (Olist 부담)** |
| 공식 번들 상품 없음 | **MD 큐레이션 번들 10개** |
| 단품 구매 유도 | **세트 구매 경험 설계** |

> BF 2017 실패 교훈: 단순 % 할인만으로는 AOV -10.1%, 다품목 +0.57%p에 그침.  
> 이번은 **할인 + 배송비 무료 + MD 큐레이션 3중 구조**로 설계한다.

## 1. 데이터 기반 카테고리 선정

### 분석 기준

3가지 지표를 조합하여 번들 적합성 스코어 산출:
1. **다품목 자연 발생 비율** — 인센티브 없이도 세트 구매 일어나는 카테고리
2. **BF 주문 볼륨** — BF 시즌 실제 수요가 큰 카테고리
3. **평균 상품가** — 배송비 무료 효과가 의미 있는 가격대

|------|---------|---------|----------------|------|---------|
| **★1** | bed_bath_table | 12.7% | **371건** | ₩27,193 | 침실·욕실 완성 세트 |
| **★2** | furniture_decor | **19.0%** | 245건 | ₩26,019 | 홈 인테리어 세트 |

> **BF 2017 실측 기준** 상위 5개 카테고리 합계: **1,213건** (BF 전체의 38.2%)

### 카테고리 간 구매 패턴 (CSV 실측)

고객이 실제로 함께 사는 조합이 번들 컨셉의 근거:

```

bed_bath_table ↔ home_confort     (38건)  →  "홈 컴포트 세트"
bed_bath_table ↔ housewares       (21건)  →  "생활 스타터 세트"
furniture_decor ↔ garden_tools    (19건)  →  "홈&가든 세트"
furniture_decor ↔ housewares      (12건)  →  "인테리어 완성 세트"
```

→ **bed_bath_table + furniture_decor + housewares 3개 카테고리는 서로 묶어 "홈 리빙 번들"로 통합 기획 가능**

## 2. 번들 상품 구성 가이드라인

### 핵심 원칙: 번들 합계 ₩40,000 이상

> **근거**: 번들 최소가와 Olist ROI의 관계

| 번들 합계 최소가 | 번들 대상 주문 | Olist ROI |
|------------|-----------|---------|
| 없음 | 1,207건 | **1.9배** |
| ₩30,000+ | 478건 | 2.7배 |
| **₩40,000+ ★** | **310건** | **3.1배** |
| ₩50,000+ | 207건 | 3.4배 |

- **최소가 없음**: BRL 5짜리 상품 2개도 배송비 무료 → Olist 부담 대비 GMV 효과 최소
- **₩50,000+**: ROI는 높지만 대상 주문이 너무 줄어 기획전 효과 체감 약화
- **₩40,000**: bed_bath_table 평균 2개 합계 ~₩54,000으로 자연 충족 가능 + ROI 3.1배

### 번들 상품 구성 조건 (셀러 가이드)

| 조건 | 기준 |
|------|------|
| 번들 합계 | **₩40,000 이상** (1번 + 2번 상품 합계) |
| 할인율 | **15%** (2번 상품 기준) |
| 배송 | **무료 (Olist 부담)** |
| 셀러 조건 | Fast-Ship 인증 셀러 우선 (배송 지연 방지) |
| 상품 조건 | 재고 30개 이상, 상품 평점 4.0 이상 |

## 3. 기대 임팩트

### 시뮬레이션 기준

- **BF 2017 실측**: 3,172건 (데이터셋 기준. 실제 BF 규모는 이보다 클 수 있음)
- **상위 5개 카테고리 BF 주문**: 1,213건
- **₩40,000 이상 번들 대상**: 310건 (26%)
- **평균 2번째 아이템 추정가**: ₩39,258 (번들 대상 주문 기준)
- **Olist 배송비**: BRL 22.78 ≈ ₩6,880

### 전환율 시나리오

> 이번이 **최초 번들 기획전**이라는 점, BF 시즌 고구매 의도, MD 큐레이션 노출 효과 반영

| 시나리오 | 전환율 | 번들 주문 | 추가 GMV | Olist 비용 | **ROI** |
|--------|------|--------|--------|---------|---------|
| 보수적 | 15% | 46건 | ₩181만 | ₩59만 | **3.1배** |
| **권고 ★** | **20%** | **62건** | **₩243만** | **₩79만** | **3.1배** |
| 낙관적 | 25% | 77건 | ₩302만 | ₩98만 | **3.1배** |

> **ROI 3.1배는 전환율에 무관하게 고정** (Olist 비용 = 배송비 + 할인 보전이 GMV에 비례하기 때문)  
> 즉, **전환율이 높을수록 절대 GMV는 커지되 ROI는 유지된다.**

### Olist 비용 구조 (20% 전환 기준)

| 항목 | 금액 |
|------|------|
| 배송비 부담 (62건 × ₩6,880) | ₩43만 |
| 번들 할인 보전 (62건 × ₩39,258 × 15%) | ₩37만 |
| **Olist 총 부담** | **₩79만** |
| **추가 GMV** | **₩243만** |
| **ROI** | **3.1배** |

### OKR 연결

| KR | 현재 | 목표 | 번들 기여 |
|----|------|------|---------|
| BF-KR2 다품목 비중 | 9.01% | 13~14% | ★ 직접 기여 (번들 구매 = 다품목) |
| BF-KR3 AOV | ₩48,575 | ₩51,340 유지 | 번들 구매로 AOV 방어 |
| KR1 재구매율 | 0.56% | 1.5~2.0% | 번들 구매자 코호트 품질 향상 |

## 4. 셀러 참여 설득

### 셀러 입장 손익 (번들 1건당)

| 항목 | 금액 |
|------|------|
| 2번째 상품 추가 판매 (기존에 안 팔렸을 재고) | **+₩39,258** |
| 번들 할인 15% 부담 | -₩5,889 |
| 배송비 부담 (Olist 지원) | **₩0** |
| **셀러 순 추가 수익** | **+₩33,369** |

→ 셀러는 할인을 제공하지만, **불확실했던 재고 판매가 +₩33,000 확정 수익으로 전환**된다.

### Olist 제공 인센티브

- 번들 상품 BF 메인 배너 + 카테고리 상단 **우선 노출**
- Fast-Ship 인증 가점 (검색 상위 노출 + 신뢰 배지)
- BF 종료 후 전환율 상위 번들 → **상시 상품 우선 등록권**
- BF 기간 번들 참여 셀러 전용 운영 리포트 제공
