## 1. 왜 지금 이 제안이 필요한가

### 1-1. BF 2017이 증명한 것: 단순 할인은 안 된다

| 지표 | BF 2017 결과 | 의미 |
|------|------------|------|
| AOV 변화 | **-10.1%** | 할인이 객단가를 갉아먹었다 |
| 다품목 비중 변화 | **+0.57%p** (9.41% → 9.98%) | 사실상 무변화 |
| 재구매 cohort 30일 | **0.56%** | BF로 만든 고객이 안 돌아왔다 |

> 결론: "BF에서 % 할인만 하면 AOV가 무너지고 다품목은 안 늘어난다."
> **번들 + Free Shipping은 이 구조를 깨는 유일한 설계 변수다.**

### 1-2. 잠재 수요는 이미 데이터로 확인됨 (CSV 기반)

| 근거 | 수치 | 시사점 |
|------|------|--------|
| 동일 셀러 다품목 주문 (자연 발생) | **8,360건 (8.67%)** | 공식 번들 없이도 이미 발생 중 |
| 그 중 동일 카테고리 내 구매 | **97.0% (8,107건)** | 카테고리 번들 설계 방향 정확 |
| 다품목 취급 셀러 수 | **1,363명 (45.9%)** | 번들 실행 기반 충분 |
| cama_mesa_banho 동카 다품목 | **1,045건 (Top 2)** | 첫 번들 카테고리 데이터 확정 |
| 배송비 불만 리뷰 | **679건 (6.3%)** | 배송비가 다품목 구매를 막고 있다는 직접 신호 |

> **핵심 프레임**: 8.67%는 공식 번들·혜택 없이 고객이 스스로 만든 수요다.
> 공식 번들 + Free Shipping 정책으로 이 잠재 수요를 **공식 채널로 흡수**하고, 신규 수요를 추가 창출한다.

## 2. 제안 개요

### 2-1. 메커니즘

```
[현재 고객 경로 — 크로스셀러 구매]
침대 (셀러A) BRL 50 + 배송비A BRL 22.78
+ 침구류 (셀러B) BRL 50 + 배송비B BRL 22.78
= 총 BRL 145.56 (₩43,959)

↓ MD 번들 제안

[After — 동일 셀러 번들 + Free Shipping]
"침실 완성 세트" (셀러A: 침대 + 침구류)
번들 가격 BRL 85 (-15%) + 배송비 BRL 0 (Free Shipping 정책)
= 총 BRL 85 (₩25,670)

고객 체감 절감: BRL 60.56 → -42%
```

### 2-2. 번들 가치의 두 원천

| 가치 | 내용 | 규모 |
|------|------|------|
| **번들 할인** | 개별 구매 대비 12~18% 할인 | BRL 15~25.5 절감 (평균 BRL 20) |
| **Free Shipping 정책A** | 동일 셀러 2개+ 구매 시 배송비 무료 | **BRL 22.78 절감 (확정)** |
| **합산 체감 절감** | 크로스셀러 대비 최대 | **-42% (BRL 60.56)** |

> **[확정] 동일 셀러 주문 = 배송비 1개** (CSV freight_value 구조 확인 완료)
>
> 배송비 절감 효과는 두 가지 시나리오에서 발생한다:
>
> **시나리오 1 — 크로스셀러 전환** (다른 셀러에서 사던 수요를 동일 셀러 번들로 전환)
> - Before: 셀러A 배송비 + 셀러B 배송비 = BRL 45.56 (2개)
> - After: 동일 셀러 번들 배송비 = BRL 0 (Free Shipping)
> - 절감: **BRL 45.56 (배송비 2개 → 0개)**
>
> **시나리오 2 — 동일 셀러 분리 주문 통합** (같은 셀러를 나눠 샀을 고객을 번들 1회로 통합)
> - Before: 셀러A 1차 주문 BRL 22.78 + 셀러A 2차 주문 BRL 22.78 = BRL 45.56 (2건)
> - After: 동일 셀러 번들 1회 주문 배송비 = BRL 0 (Free Shipping)
> - 절감: **BRL 45.56 (2회 → 1회, Free Shipping 적용)**
>
> **두 시나리오 공통**: 번들 + Free Shipping = 배송비 최대 2개 → 0개. BRL 22.78 → BRL 45.56 절감.

## 4. Free Shipping 정책 옵션 비교

### Option A: Olist 직접 부담

> **구조**: 번들 구매(동일 셀러 2개+) 시 Olist가 배송비를 보조

**비용 계산 (BF 1주 기준):**

| 항목 | 계산 | 수치 |
|------|------|------|
| 번들 전환 주문 수 | ~78건 (3.52%p 전환분) | BF 1주 |
| Olist 배송비 보조 비용 | 78건 × ₩6,880 | **₩54만** |
| 번들 추가 GMV | 78건 × ₩30,000 | **₩234만** |
| **ROI** | ₩234만 / ₩54만 | **4.3배** |

| 장점 | 단점 |
|------|------|
| 고객 UX 단순 — "번들 = 무료 배송" | Olist 직접 비용 발생 (BF 주 ₩54만, 상시화 시 월 ~₩200만 추정) |
| 셀러 마찰 없음, 즉시 실행 가능 | 정책 남용 가능성 (다품목 주문 위장) |
| 프로모션 속도 빠름 | 경영진 예산 확정 전 실행 불가 |
| 셀러 협의 없이 Olist 단독 결정 | 배송비 구조 왜곡 위험 (상시화 시) |

---

### Option B: 셀러 부담 + 인센티브 제공

> **구조**: 셀러가 번들 상품 등록 시 "배송비 무료" 옵션 선택. 대신 Olist가 셀러에게 인센티브 제공.

**셀러 수익 구조 (번들 1건당):**

| 항목 | 단품 판매 (현재) | 번들 판매 (Option B) | 차이 |
|------|--------------|------------------|------|
| 2차 아이템 추가 수익 | 불확실 (별도 구매 필요) | +₩30,000 (확정) | **+₩30,000** |
| 번들 할인 15% (2차 기준) | - | -₩4,500 | -₩4,500 |
| 배송비 부담 | - | -₩6,880 | -₩6,880 |
| **셀러 순 추가 수익** | 0 | | **+₩18,620** |

> **핵심 논거**: 셀러는 배송비 ₩6,880을 부담하지만,
> 불확실했던 2차 아이템 판매가 **확정 수익 +₩18,620으로 전환**된다.
> 즉, 배송비 부담 대비 수익 배수 = **₩18,620 / ₩6,880 = 2.7배**.

**Olist가 제공하는 추가 인센티브:**

| 인센티브 | 내용 | 셀러 기대 효과 |
|---------|------|-------------|
| **메인 배너 우선 노출** | BF 기간 번들 상품 카테고리 상단 고정 | 전환율 증가 (노출 → 구매) |
| **Fast-Ship 인증 가점** | 번들 참여 셀러에 TF1 Fast-Ship 인증 우선 부여 | 검색 상위 노출 + 신뢰도 배지 |
| **BF Seller Ops 전담 지원** | 번들 참여 셀러 전용 재고 관리·발송 가이드 | 운영 리스크 감소 |
| **재고 소진 가속** | 번들 = 1건에 2SKU 출고 | 재고 회전율 개선 |
| **BF 이후 번들 상시화 우선권** | BF 검증 번들 → 상시 상품 전환 시 우선 등록 | 중기 안정 수익 확보 |

| 장점 | 단점 |
|------|------|
| Olist 직접 배송비 비용 없음 | 셀러 협의 최소 6주 리드타임 필요 → **9월 착수 필수** |
| 셀러 자발 참여 → 번들 품질 유지 | 마진 얇은 셀러는 참여 거부 가능 |
| Fast-Ship 우수 셀러만 선별 → TF1 배송 품질 유지 | 초기 번들 수 10개 달성 불확실 |
| 중기 상시화 구조로 자연 전환 | 참여율 낮으면 BF-KR2 목표 달성 어려움 |

## 5. 두 옵션 최종 비교

| 기준 | Option A (Olist 부담) | Option B (셀러 부담 + 인센티브) |
|------|---------------------|----------------------------|
| **BF-KR2 달성 속도** | 빠름 (정책 확정 즉시) | 셀러 협의 6주 필요 |
| **Olist 비용** | BF 1주 ₩54만 / 상시 월 ~₩200만 | 없음 (인센티브 운영비 별도) |
| **배송 품질 보장** | ❌ 모든 다품목 주문에 적용 → 품질 통제 어려움 | ✅ Fast-Ship 셀러만 참여 |
| **지속 가능성** | 상시화 시 비용 급증 위험 | 셀러 수익 구조에 내재화 → 지속 가능 |
| **셀러 참여도** | 높음 (무조건 혜택) | 중간 (인센티브 설득 필요) |
| **TF1 연계성** | 낮음 | ✅ Fast-Ship 인증과 직접 연동 |
| **추천** | BF 긴급 대응 / 실험용 | **중장기 구조화 정책 ★** |

> **MD팀 권고**: Option B를 기본 정책으로, Option A는 BF 실험 1회로 운영.
> BF에서 Option A(Olist 부담)로 전환율 데이터 확보 → 그 결과로 Option B 셀러 설득 근거 생성.
> 즉, **A로 검증 → B로 구조화**하는 2단계 전략이 최적.
