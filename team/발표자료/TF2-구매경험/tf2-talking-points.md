## 🎯 핵심 설득 포인트 5개

### 1️⃣ 왜 TF2가 필요한가 — 저평점 원인이 4팀에 분산

| 원인 | 비중 | 책임 팀 |
|---|---|---|
| 미배송 / 배송 지연 | **42%** | Logistics |
| **CS 무응답** | **19.8%** | CX |
| 제품 불량 | 9.2% | Seller Ops |
| 기타 (UX 등) | 18% | Product |

→ 한 팀 단독 풀이 불가. **공동 KR + 팀별 기여 KR** 구조로만 풀린다.

### 2️⃣ 왜 5점만 재구매가 일어나는가 — TF3 핸드오프 메커니즘

- 1·2·3·4점 재구매 **~2.5%** (동일)
- **5점만 3.12%** (유일하게 튐)
- 5점을 만드는 것은 **정시 배송**: 3.04% vs 지연 2.51% (−0.53%p)
- → "유저 만족도 ↑ → 평점 ↑ → 재구매" 메커니즘이 **TF3로 넘기는 지점**

### 3️⃣ PDP — 신뢰 정보 4종 배치 구조 (산출물 ①)

- **변수 통제**: 가격·CTA·옵션 동일 / 변경 변수는 **신뢰 박스 4종**(별점·배송·반품·셀러) 유무
- After: ⭐ 4.7 + 🚚 도착일 명시 + ↻ 30일 반품 + 🛡 Fast-Ship 인증
- 데이터 정합: 27,300원 ≈ 85 BRL — Olist `bed_bath_table` 침구 중앙값(79 BRL) 정합
- 카테고리 선정 근거: bed_bath_table = Olist **재구매율 1위 6.42%** (TF3 침구 크로스셀과 시각 동선 일관)

### 4️⃣ CX 48h SLA (산출물 ②)

- 저평점 리뷰의 **19.8%가 문의 무응답**에서 발생
- 정시 배송인데도 1점 준 고객 **6,122명** 중 11.4%가 CS 무응답 원인
- 48h SLA + 분류 자동화 + 6시간 배정 → 19.8% → **5% 이하** 기대
- 핵심 멘트: *"배송만 고쳐서는 절반만 해결"*

### 5️⃣ Thank-you 페이지 — D+0 트리거 보드 ★ (산출물 ③, 발표 정점)

- 현재 평균 주문 수 **1.0334** (한 번 사면 끝나는 구조)
- 일회성 고객 **90,315명** vs 충성 고객 **227명** → 격차 좁히는 핸드오프 구조 필요
- D+0 7블록 → D+7 푸시 / D+30 이메일 / D+60 카톡 시계열 발화
- 침구 카테고리 6.42% 재구매율을 **크로스셀 데이터 근거**로
- **TF3 7터치포인트 Journey Map의 출발선** = 발표 후반부 시각적 정점

## ❓ Q&A 대비

| 질문 | 답변 |
|---|---|
| 왜 한국 G마켓 톤? | 청중 직관성 위해 단순화. 가격 27,300원 ≈ 85 BRL로 Olist 침구 중앙값(79 BRL) 정합 — 데이터 신뢰성 유지 |
| 왜 베개? | bed_bath_table = Olist **재구매율 1위 카테고리**. 가격·무게가 평균에 가장 가까운 단품. 데이터 정합성 최대 |
| 왜 4채널 (Push/Email/Kakao)? | 평균 주문 1.03 → 한 화면 D+0이 시계열로 4채널 발화. 정적 4훅 X, **동적 시계열** ✓ |
| TF3와의 차이? | TF2 = "첫 경험 만족" / TF3 = "재구매 자동화". **Thank-you 페이지가 핸드오프 지점** |
| 카카오 플친? 한국 콘셉트? | 청중 이해 위해 한국 채널 톤 차용. 실 적용 시 브라질 채널 (WhatsApp Business) 매핑 |
| 신뢰 박스 4종 효과 측정? | A/B 테스트 (ratio 50:50) — 1차 KR: 5점 비중 / 2차 KR: 30일 재구매율 |
