## 3. 스토리텔링 원칙

### 3-1. 도입부 (슬1~3) — 캐릭터·시나리오 셋업

```
슬1 표지     → "이건 컨설팅 보고서다"
슬2 의뢰     → "클라이언트 Olist가 왜 우리를 불렀는가"
슬3 우리     → "그래서 우리(데2터로말해조)는 누구인가"
   ↓
슬4 결론     → "결론부터 드립니다 — 재구매 구조가 없습니다"
```

### 3-2. 연역 구조 (슬4부터)

```
결론 먼저 (슬4):
  "Olist에는 재구매 구조가 없습니다. 작년 BF 이후 30일 재구매율 0.56%."

근거 연결 고리:
  근거 1 (현황): 데이터를 보면 97%가 이탈한다 (EDA · RFM)
  근거 2 (병목): 수식·여정 모두 Retention이 무너져 있다 (KPI Tree × AARRR)
  근거 2.5 (🔥 피크): 재구매는 '5점'에서만 만들어지고, 5점은 '배송'이 결정한다
  근거 3 (원인): ① 배송 ② 첫 경험 ③ 재구매 유도 3가지 (Finding · 가설 검증)

솔루션 (TF):
  → 한 팀이 못 푼다. 4개 팀에 분산.
  → TF 3개로 묶었다 (배송 품질 / 첫 경험 / 재구매 유도)

결론 재선언 (Act 7):
  "재구매율 3.0% → 4.5%, BF cohort 0.56% → 1.5~2.0% 달성"
  + CTA: 이번 주 / 이번 달 / BF까지 / BF 이후 1년
```

### 3-3. 이중 트랙 메시지

> **"TF는 BF로 증명, 구조 개선은 1년으로 완성"**
