### 현황 요약

|------|------|------|

### 비즈니스 특성 해석

현재 Olist의 **낮은 재구매율(3%)**은 단순한 "운영 문제"가 아닙니다.

```
📊 카테고리 분석 결과

1순위: health_beauty (9.4%)
2순위: bed_bath_table
3순위: sports_leisure

🔴 특이사항: 고가 카테고리(computers, air_conditioning)는
   건수 적지만 GMV 기여도 큼
   → 고가 상품 비중이 높으면 재구매율이 낮을 수밖에 없음

💡 해석:
- 가구, 가전, 의류 같은 "저빈도 구매" 카테고리가 메인
- 구매 주기가 6개월~2년 이상인 상품들
- 따라서 "재구매율 3%"는 비즈니스 구조의 필연적 결과일 수 있음

🎯 결론:
"재구매율 3%를 일반적인 유통사처럼 20% 이상으로 올릴 수는 없다"
대신 "같은 고객의 LTV(생애가치)를 높이고, 
구매 주기 내에서의 engagement를 강화"해야 함
```

## 🎯 10대 컨설팅 액션

### 액션의 우선순위 기준

1. **임팩트**: 재구매율 vs 주문당 매출액(AOV)에 미치는 영향
2. **실행 난이도**: 의사결정부터 실행까지의 복잡도
3. **타이밍**: 11-12월 Black Friday 효과를 낼 수 있는가?
4. **시너지**: 다른 액션과의 상호작용

## 🥇 임팩트 초고: 재구매 × LTV 동시 해결 (액션 1-3)

### **액션 1: 카테고리별 맞춤형 첫 구매 후 CRM**

**관점**: 마케팅/리텐션  
**임팩트**: 재구매율 +1~2% (3% → 4~5%)  
**실행 난이도**: 중간  

#### 배경
- 고가 상품이 많으면 구매 주기가 길다
- 구매 후 고객이 "다음 구매"를 인지하지 못함
- 3% 재구매율 중 상당 부분은 "의도적 재구매"가 아니라 "우연한 재구매"

#### 구체적 액션

**카테고리별 전략**:

| 카테고리 | 주기 | CRM 전략 |
|----------|------|---------|
| health_beauty | 1개월 | 배송 완료 7일 후 "새상품 추천" (BRL 50-100 / 약 18,500-37,000원 범위) |
| bed_bath_table | 3개월 | 배송 완료 60일 후 "계절상품" (BRL 80-150 / 약 29,600-55,500원 범위) |
| computers/air | 1년+ | 배송 완료 180일 후 "액세서리/소모품" (BRL 100-300 / 약 30,200~90,600원 범위) |
| sports_leisure | 2개월 | 배송 완료 30일 후 "관련상품" (BRL 60-120 / 약 22,200-44,400원 범위) |

**구체 실행**:
1. 배송 완료 후 자동화된 이메일/SMS 시퀀스
2. 카테고리별 평균 재구매 주기 계산
3. 재구매 주기 진입 60-90일 전부터 engagement (email + app notification)
4. 재구매 특화 쿠폰 (첫 구매 카테고리 관련 상품 20% 할인)

#### 기대효과
- 재구매율 +1~2%포인트
- 평균 재구매 주기 단축 (무의식적 재구매 → 의식적 재구매)
- 고객 LTV +15~20%

#### 우선순위
🔴 **최우선** — 9월 즉시 시작, 10월 중 full roll-out

### **액션 2: 고가 상품(고가 카테고리) 특화 Post-Purchase Service**

**관점**: 상품기획/고객경험  
**임팩트**: 재구매율 +0.5~1%, 리뷰 평점 +0.2~0.3점  
**실행 난이도**: 중간~높음

#### 배경
- computers, air_conditioning 같은 고가 상품은 구매 후 기대값이 높음
- 배송 후 "정상 작동 확인", "설치", "AS 안내" 부족
- 첫 구매 경험 부족 → 저평점 → 재구매 회피

#### 구체적 액션

**고가 상품 구간별 서비스**:

**배송 직후 (0~1일)**:
- 자동 배송 완료 메시지 + "설치가이드" 영상 링크
- "만약의 문제" 대비 AS 연락처 명확히

**사용 초기 (1~7일)**:
- 자동 확인 메시지 "제품 정상 작동하시나요?"
- 문제 신고 시 48시간 내 대응 약속

**사용 중기 (30일)**:
- "사용 팁" 이메일 (유지보수, 성능 최적화)
- "만족도 조사" 후 문제 사항 빠른 resolution

**1년 단위**:
- 연간 AS 확인 (정기 점검 안내)
- "신제품 출시" 특별 할인 (기존 고객)

#### 기대효과
- 첫 구매 저평점 감소 (12.82% → 10%)
- 고가 상품 만족도 향상
- 재구매율 +0.5~1%포인트 (고가 상품 카테고리에서)

#### 우선순위
🟠 **높음** — 9월 설계, 10월 pilot (computers만), 11월 확대

---

### **액션 3: 할부 결제자 특화 재구매 유도 프로그램**

**관점**: 마케팅/재무  
**임팩트**: 재구매율 +0.3~0.7%, AOV +5%  
**실행 난이도**: 낮음

#### 배경
- 결제 패턴 분석: 신용카드 70%+, 할부 2~10개월 고르게 분포
- 고가 상품 구매자는 할부 결제 많음
- **할부 진행 중인 고객**이 다른 상품도 구매할 심리적 진입장벽 낮음 (이미 월 납부에 익숙)

#### 구체적 액션

**할부 결제자 Cohort 분석**:
1. 할부 진행 고객 (2~10개월) 식별
2. 할부 완료 예정일 90일 전부터 targeting
3. "할부 완료 축하 + 신상품 특별 할인" 캠페인

**구체 실행**:
- "마지막 할부금 1개월 남음" 시점에 이메일
- "완제 축하 50% 할부 가능" 프로모션
- 이전 구매 카테고리 연관 상품 추천

**예시**:
- 가구 구매자 (할부 진행 중, BRL 300 / 약 90,600원)
  → 할부 완료 1개월 전 수신
  → "쿠션 BRL 50 (약 15,100원), 러그 BRL 80 (약 24,160원) 할부 구매 0% 이자" 프로모션
  → "설치비 무료" 등 추가 가치 제공

#### 기대효과
- 할부 결제자의 재구매율 +1~2%포인트
- 다품목 구매 유도
- AOV +5~8%

#### 우선순위
🟡 **중~높음** — 10월 시작, 11월 Black Friday 연계

## 🥈 임팩트 고: Activation 개선 (액션 4-5)

### **액션 4: 배송 지연 다발 지역·카테고리·셀러 SLA 강화**

**관점**: 운영/물류  
**임팩트**: 재구매율 +0.3~0.5%, 리뷰 평점 +0.3점  
**실행 난이도**: 낮음~중간

#### 배경
- 배송 지연율 6.8% (약 10건 중 1건)
- 배송 지연 주문의 평점이 정시 배송 대비 0.5~1.0점 낮음
- **첫 구매에서 지연되면 재구매 가능성 급락**

#### 구체적 액션

**Step 1: 지연 분석** (9월)
- 지역별 지연율 (SP, RJ vs 기타)
- 카테고리별 지연율 (고가/무거운 상품)
- 셀러별 지연율 (상위 544명 중 특히 문제 셀러)

**Step 2: 문제 셀러/지역 식별** (9월)
- 지연율 상위 10% 셀러 리스트업
- 지역별 배송 파트너 성과 분석

**Step 3: SLA 강화** (10월)
- 지연율 높은 셀러: 배송 예정일 -2일 pick 의무화
- 지연 다발 지역: 배송 파트너 다양화 또는 교체
- 고가 상품: 예상 배송일 +1일 buffer 제공

**Step 4: 모니터링** (10월~11월)
- 주간 지연율 모니터링
- Black Friday 대비 capacity 확보

#### 기대효과
- 배송 지연율 6.8% → 4~5%로 감소
- 첫 구매 만족도 향상
- 재구매율 +0.3~0.5%포인트

#### 우선순위
🔴 **최우선** — 9월 즉시 분석, 10월 실행, 11월 안정화

### **액션 5: 첫 구매 저평점(12.82%) 원인 분석 및 Seller 교육**

**관점**: 상품기획/운영  
**임팩트**: 재구매율 +0.2~0.3%, 리뷰 평점 +0.2점  
**실행 난이도**: 중간

#### 배경
- 첫 구매 저평점(1~2점): 12.82%
- 배송 지연과 저평점의 상관성 있음 (배송 지연 → -0.5~1점)
- 나머지는 상품 기대 불일치, 상품 설명 부족, 포장 문제

#### 구체적 액션

**첫 구매 저평점 분석** (9월):
1. 저평점 리뷰 텍스트 분석 (상위 100개)
   - 배송 지연 언급
   - 상품 설명과 실제 상품 불일치
   - 포장/손상
   - 상품 기능 문제
   
2. 카테고리별 저평점 원인 파악
   - health_beauty: 색상 불일치 (많음)
   - bed_bath: 사이즈 불일치 (많음)
   - computers: 배송 손상 (많음)

**Seller 교육** (10월):
- 상품 사진 quality 기준 강화 (다각도, 사이즈 비교)
- 상품 설명 템플릿 제공 (사이즈, 소재, 주의사항)
- 포장 기준 강화 (파손 예방)

**자동화** (10월~11월):
- 첫 구매 고객 대상 "상품 도착 후 체크리스트" 자동 메시지
- 문제 발생 시 빠른 환불/교환 프로세스 (48시간 대응)

#### 기대효과
- 첫 구매 저평점 12.82% → 11%로 감소
- 리뷰 평점 +0.2점
- 재구매율 +0.2~0.3%포인트

#### 우선순위
🟠 **높음** — 9월 분석, 10월 교육, 11월 효과 측정

## 🥉 임팩트 중~높음: 다품목 & AOV (액션 6-7)

### **액션 6: 카테고리 조합 추천 (High-Ticket + 저가 액세서리)**

**관점**: 상품기획/마케팅  
**임팩트**: AOV +10~15%, 다품목율 +3~5%포인트  
**실행 난이도**: 중간

#### 배경
- 현재 AOV BRL 138, 다품목율 10% 미만
- 고가 상품(가구, 가전) 구매 고객은 **관련 저가 액세서리 구매 의향 높음**
- 배송료 구조상 다품목 구매가 buyer도 seller도 이득

#### 구체적 액션

**카테고리 Pair 분석** (9월):
- 함께 자주 구매되는 상품 조합 분석
- 예:
  - 침대 → 침구류 (50% 함께 구매 가능성)
  - 소파 → 쿠션 (40%)
  - 냉장고 → 음료 보관용품 (30%)

**추천 로직** (10월):
1. **주문 직후 추천**
   - 배송 대기 중: "이 상품과 함께 어떨까?" 이메일
   - 구매 상품 정보 활용 (카테고리 + 가격대)
   
2. **배송 완료 후 추천**
   - "맞춤 액세서리" 할인쿠폰
   - "함께 사면 배송료 무료" 프로모션

**예시**:
```
구매: 침대 (BRL 500 / 약 151,000원)
→ 이메일 추천
  - 침구류 세트 (BRL 80 / 약 24,160원) "20% 할인"
  - 베개 커버 (BRL 30 / 약 9,060원) "함께 구매 시 배송료 무료"
→ AOV BRL 500 → 610 (약 151,000원 → 약 184,220원) (+22%)
```

#### 기대효과
- AOV +10~15%
- 다품목율 +3~5%포인트
- 배송 효율성 증가 (같은 shipment에 여러 상품)

#### 우선순위
🟡 **중~높음** — 10월 pilot, 11월 확대

---

### **액션 7: 번들 상품 & 세트 프로모션 (Black Friday 중심)**

**관점**: 상품기획/마케팅  
**임팩트**: AOV +15~20%, 다품목율 +5~8%포인트, 11월 매출 +10%  
**실행 난이도**: 낮음

#### 배경
- Black Friday (11월 마지막 주) 고객의 구매 의향 높음
- **번들 상품은 "품질 신호"와 "가치감" 동시 제공**
- 다품목 구매 유도 최고의 기회

#### 구체적 액션

**번들 상품 구성** (10월):
1. 방 꾸미기 패키지
   - 침대 + 침구류 + 베개 + 조명 (번들가 BRL 700 / 약 211,400원)
   - 개별 구매 대비 15% 할인
   
2. 주방 완성 패키지
   - 냉장고 + 식탁 + 의자 4개 (번들가 BRL 1,200 / 약 362,400원)
   - 개별 구매 대비 12% 할인

3. 운동 홈짐 패키지
   - 러닝머신 + 아령 세트 + 매트 (번들가 BRL 800 / 약 241,600원)
   - 개별 구매 대비 18% 할인

**프로모션 타이밍** (11월):
- 11월 1주: 조기 예약 (배송 11월 마지막주)
- 11월 마지막주 (Black Friday): 스포트 프로모션
- "오늘 구매 시 배송료 무료" 등 긴급감 연출

#### 기대효과
- AOV +15~20%
- 다품목율 +5~8%포인트
- 11월 매출 +8~12%
- 고객 LTV +25~30%

#### 우선순위

## 최종 메시지: 팀에게 전하는 말

> **Olist의 재구매율 3%는 "운영 실패"가 아니라 "고가 상품 중심 비즈니스의 특성"입니다.**
> 
> 따라서 "재구매를 3번으로 늘린다"는 비현실적 목표가 아니라,
> **"같은 고객의 생애가치(LTV)를 3배로 늘린다"**는 목표로 접근해야 합니다.
> 
> 1차 구매 후 CRM → 구매 주기 내 engagement → 2차 구매 시 다품목 유도 → LTV 극대화
> 
> 이 흐름 속에서 11월 Black Friday는 **"2차 구매의 황금 기회"**입니다.
> 
> 9월부터 의도적으로 준비하면, 12월에는 새로운 성장 모멘텀을 만들 수 있습니다.
