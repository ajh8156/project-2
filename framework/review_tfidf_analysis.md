> **작성일**: 2026-04-04

> **분석 목적**: 수치로만 확인된 "재구매율 3%, 배송 지연율 8.13%"의 실제 고객 이탈 원인 파악

## 1. TF-IDF 분석 — 키워드로 불만 원인 추출

### 접근 방식

저평점(1~2점) 리뷰 텍스트에서 **어떤 단어가 이 리뷰들을 특징짓는지** 추출했다.
TF-IDF는 "이 리뷰 집합에서 자주 등장하면서, 다른 리뷰에서는 잘 안 나오는 단어"에 높은 점수를 부여하는 방식이다.
추출된 키워드를 기반으로 6개 불만 카테고리로 분류했다.

### 발견된 인사이트

**Top 키워드**

| 키워드 | 의미 | 시사점 |
|--------|------|--------|
| ainda | 아직 | "아직도 안 왔다" — 배송 대기 중 리뷰 작성 |
| entregue | 배달됨/안됨 | 배송 관련 언급 압도적 1위 |
| aguardando | 기다리는 중 | 배송 미도착 상태 |
| demora | 느림/지연 | 배송 속도 불만 |
| defeito | 결함 | 제품 품질 불만 |
| errado | 틀림/오배송 | 상품 오배송 |
| reembolso | 환불 | 환불 요청 |

→ 키워드만 봐도 **배송이 불만의 핵심**임이 명확하게 드러난다.

**불만 원인 분류 결과**

| 불만 원인 | 건수 | 비율 |
|---------|-----:|----:|
| **기타/불명확** | **5,448건** | **51.3%** |
| 미배송 | 2,210건 | 20.8% |
| 환불/CS 무응답 | 1,084건 | 10.2% |
| 배송 지연 | 1,055건 | 9.9% |
| 제품 불량 | 996건 | 9.4% |
| 기대 불일치 | 641건 | 6.0% |
| 포장 불량 | 400건 | 3.8% |

### TF-IDF의 한계

분류 결과의 **51.3%가 "기타/불명확"** 으로 남았다.

원인은 명확하다. TF-IDF는 **특정 키워드가 있어야만 분류**할 수 있는데,
실제 불만 리뷰의 상당수는 *"Péssimo"(최악)*, *"Horrível"(끔찍해)* 처럼
감정만 표현하고 **원인을 직접 언급하지 않는** 경우가 많다.

즉, "왜 화났는지"를 말하지 않고 "얼마나 화났는지"만 쓴 리뷰들이 전부 미분류로 남는 구조적 한계가 있다.

## 2. 딥러닝 분석 — 의미 기반 분류로 한계 극복

### 접근 방식

`paraphrase-multilingual-MiniLM-L12-v2` 모델(다국어 사전학습, ~470MB)을 활용했다.

키워드 매칭 대신, **텍스트 전체의 의미를 벡터로 변환**한 후 각 불만 카테고리의 설명문과 코사인 유사도를 계산해 가장 가까운 카테고리로 분류하는 Zero-shot 방식이다. 별도 학습 데이터 없이 의미만으로 분류한다.

```
리뷰 텍스트 → 벡터화 → 각 카테고리 설명문과 유사도 비교 → 분류
```

### TF-IDF 한계 해소 결과

![TF-IDF vs 딥러닝 비교](../charts/review_02_tfidf_vs_dl.png)

| 불만 원인 | TF-IDF | 딥러닝 | 변화 |
|---------|-------:|------:|:---:|
| **기타/불명확** | **51.3%** | **0%** | 완전 해소 |
| 미배송 | 20.8% | 42.0% | ↑ |
| 환불/CS 무응답 | 10.2% | 19.8% | ↑ |
| 배송 지연 | 9.9% | 8.7% | ≈ |
| 제품 불량 | 9.4% | 9.2% | ≈ |
| 기대 불일치 | 6.0% | 8.5% | ↑ |
| 포장 불량 | 3.8% | 5.5% | ↑ |
| **가격/배송비** | **없음** | **6.3%** | 🆕 신규 발견 |

분류 신뢰도(코사인 유사도 0.4 이상): **80.8%**

미배송이 20.8% → 42.0%로 크게 늘어난 이유는, TF-IDF가 잡지 못했던
*"ainda não chegou"(아직 안 왔어요)* 같이 키워드 없이 상황만 서술한 표현들을
딥러닝이 의미로 포착했기 때문이다.

## 3. 딥러닝 분석을 통해 확인된 핵심 인사이트

### 인사이트 1 — 배송 지연이 별점을 결정한다

![배송 지연 vs 저평점](../charts/review_01_delay_vs_lowscore.png)

배송이 지연되면 저평점 비율이 **54%** — 정시 배송의 9.2%와 **5.9배 차이**다.
배송 지연은 단일 요인으로는 고객 이탈에 가장 강력하게 작용한다.

---

### 인사이트 2 — 배송이 정시여도 1점인 고객이 6,122명 있다

![배송 정시 1점 원인](../charts/review_04_ontime_1star.png)

배송이 제때 도착했음에도 별점 1점을 준 케이스를 별도로 분석했다.
결과: 제품 불량(12%), CS 무응답(11.4%), 기대 불일치(7.4%)가 독립적 이탈 원인으로 존재한다.

**배송만 개선해서는 저평점의 절반을 해결할 수 없다.**

---

### 인사이트 3 — 카테고리마다 불만의 성격이 다르다

![카테고리별 배송 지연율](../charts/review_03_category_delay.png)

| watches_gifts | 환불/CS 무응답 | AOV ₩64,413으로 고가. CS 기대치가 높아 응답 지연에 민감 |
| bed_bath_table | 기대 불일치 두드러짐 | 색상·사이즈 불일치 — 상품 등록 가이드 강화 필요 |
| computers_accessories | 제품 불량·정품 의심 | "original(정품)" 키워드 반복 — 셀러 정품 인증 검토 |

---

### 인사이트 4 — 배송비가 다품목 구매의 장벽이다 (신규 발견)

딥러닝 분류에서 기존 분석에 없던 **가격/배송비 불만 679건(6.3%)** 이 발견됐다.

대표 리뷰:
> *"Frete muito caro"* — 배송비 너무 비쌈
> *"mesmo comprando mais itens, vai ficando mais caro"* — 아이템 더 사도 더 비싸짐

현재 Avg Items/Order가 **1.14개**로 단품 위주인 상황에서, 다품목 구매 유도 전략의 실질적 장벽이 배송비임을 고객 목소리로 확인한 것이다.
